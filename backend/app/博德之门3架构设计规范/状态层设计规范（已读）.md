> ❸ 状态层 = 游戏世界的"当前现实"，所有系统读写的唯一真理来源。
> 采用 **State Slice 注册制**：每个子系统拥有并管理自己的状态切片，状态层是容器 + 注册表。

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **唯一真理** | 所有系统读写同一份状态，不存在分裂（P3） |
| **切片自治** | 每个子系统拥有自己的切片，定义 schema + read/write API |
| **持续可扩展** | 新增子系统 = 新增切片 + 注册，零侵入现有代码 |
| **权限隔离** | L2 按角色暴露切片的不同访问级别（只读 / 角色权限写 / 完整写） |
| **机械确定性** | 状态变更**主路径**通过 ❷ 规则引擎（Command → Handler → StateDelta）。**受控例外**（格级缓冲写入、编排层内部调度、队伍管理）须有明确审计来源——详见 §四(附) 受控例外表 |

## 二、整体架构：StateContainer + Slice 注册表

```
StateContainer（状态容器，会话级单例）
    │
    │  职责：
    │  - 持有所有已注册切片的引用
    │  - 统一生命周期（restore / persist / snapshot）
    │  - 提供跨切片查询接口（给 ContextAssembler 用）
    │  - dirty tracking 汇总
    │
    │  接口：
    │  - get_slice(name) → Slice
    │  - snapshot() → 全局快照（给 AI Osiris 用）
    │  - restore(session_data) → 从持久化数据恢复所有切片
    │  - persist() → 遍历所有切片，持久化 dirty 数据
    │  - register(name, slice) → 注册新切片
    │
    ├─ TimeSlice
    ├─ PlayerSlice
    ├─ RelationSlice
    ├─ QuestSlice
    ├─ FlagSlice
    ├─ AreaSlice
    ├─ EventSlice
    ├─ PartySlice
    ├─ SceneSlice
    ├─ NarrativePlanSlice          ← NarrativePlanner 规划状态（详见 `叙事规划子系统设计规范.md` §七）
    └─ ... 未来扩展
```

### 2.1 Slice 基类

每个切片实现统一接口：

```python
class StateSlice(ABC):
    """状态切片基类"""

    @property
    @abstractmethod
    def name(self) -> str:
        """切片名称，用于注册和寻址"""

    @abstractmethod
    def restore(self, data: dict) -> None:
        """从持久化数据恢复"""

    @abstractmethod
    def serialize(self) -> dict:
        """序列化为可持久化的数据"""

    @abstractmethod
    def snapshot(self) -> dict:
        """生成只读快照（给 AI Osiris / ContextAssembler）"""

    @property
    def dirty(self) -> bool:
        """是否有未持久化的变更"""
```

### 2.2 StateContainer

```python
class StateContainer:
    """状态容器——所有切片的注册表和生命周期管理器"""

    def __init__(self):
        self._slices: dict[str, StateSlice] = {}

    def register(self, slice: StateSlice):
        self._slices[slice.name] = slice

    def get_slice(self, name: str) -> StateSlice:
        return self._slices[name]

    # 便捷访问器（高频切片直接暴露）
    @property
    def time(self) -> TimeSlice: ...
    @property
    def player(self) -> PlayerSlice: ...
    @property
    def relations(self) -> RelationSlice: ...
    @property
    def quests(self) -> QuestSlice: ...
    @property
    def flags(self) -> FlagSlice: ...

    def snapshot(self) -> dict:
        """全局快照，供 AI Osiris 和 ContextAssembler 使用"""
        return {name: s.snapshot() for name, s in self._slices.items()}

    def restore(self, session_data: dict):
        for name, s in self._slices.items():
            if name in session_data:
                s.restore(session_data[name])

    def persist(self) -> dict:
        """只持久化 dirty 切片"""
        result = {}
        for name, s in self._slices.items():
            if s.dirty:
                result[name] = s.serialize()
        return result
```

### 3.1 TimeSlice — 时间子系统

```python
class TimeSlice(StateSlice):
    name = "time"

    # --- schema ---
    day: int                    # 当前天数（从 1 开始）
    slot: int                   # 当前格编号（1-24）
    period: str                 # 时段：dawn / day / dusk / night
    action_count: int           # 格内动作计数（累积 6 次 = 1 格）
    accumulated: float          # 格内累积时间消耗（>= 1.0 触发结算）

    # --- read API ---
    def get_current_time(self) -> dict:
        """返回 {day, slot, period}"""

    def get_period_info(self) -> dict:
        """返回当前时段属性（危险系数、营业状态、NPC 活动）"""

    # --- write API ---
    def advance(self, slots: int = 1):
        """推进 N 格，自动处理时段切换和日期翻转"""

    def add_action(self, cost: float):
        """累积动作时间成本"""

    def reset_action_count(self):
        """格结算后重置"""
```

```python
class PlayerSlice(StateSlice):
    name = "player"

    # --- schema ---
    # 基础属性
    character_id: str
    character_name: str
    level: int
    xp: int
    hp: int
    max_hp: int
    ac: int
    stats: dict                 # {str: 10, dex: 14, con: 12, int: 13, wis: 11, cha: 15}
    proficiency_bonus: int

    # 职业
    character_class: str        # 基础职业
    subclass: str | None        # 进阶转职（6 级解锁）
    class_features: list[str]   # 已解锁的职业特性

    # 经济
    gold: int

    # 位置
    current_area: str           # 区域 ID
    current_location: str | None # 子地点 ID（可为空 = 在区域大地图）

    # 背包 & 装备
    inventory: list[ItemStack]  # 背包物品（堆叠存储）
    equipment: dict[str, Item | None]  # 13 槽位 → 装备的物品
    # 槽位：head, chest, gloves, boots, cloak, amulet, ring_l, ring_r,
    #       main_hand, off_hand, ranged, ammo, belt

    # 公会
    guild_rank: str             # porcelain / bronze / silver / gold / platinum
    guild_reputation: int       # 公会声望值

    # === 法术系统 ===
    spell_slots: dict[int, SpellSlotState]
    # 法术位等级(1-5) → SpellSlotState
    # SpellSlotState = {
    #   current: int,           # 当前剩余
    #   max: int,               # 该等级最大数量
    # }
    # 非施法职业为空 dict。从 ClassTemplate.SpellcastingConfig 初始化。

    known_spells: list[str]         # 已知法术/戏法 ID 列表
    prepared_spells: list[str]      # 当日准备法术列表（准备型施法者）
                                     # 已知型施法者: prepared_spells = known_spells（自动同步）

    concentration: ActiveConcentration | None
    # ActiveConcentration = {
    #   spell_id: str,           # 正在专注的法术
    #   target_ids: list[str],   # 影响目标列表
    #   remaining_duration: int, # 剩余回合数（-1 = 无限直到打断）
    #   applied_effects: list[str],  # 此法术施加的效果 instance_id 列表（打断时一并移除）
    # }

    # === 状态效果（运行时实例） ===
    active_effects: list[ActiveEffect]
    # ActiveEffect = {
    #   instance_id: str,        # 运行时唯一 ID
    #   effect_id: str,          # 引用 ❶ StatusEffectTemplate.id
    #   source: str,             # 施加者: "self" / character_id / monster_id / "environment"
    #   remaining_duration: int, # 剩余回合数（-1 = 直到显式移除）
    #   applied_at_tick: int,    # 施加时的游戏 tick
    #   save_dc: int | None,     # 回合结束豁免 DC（来自施法者或固定值）
    #   from_concentration: bool, # 是否由专注法术维持
    #   stack_count: int,        # 1=非可叠加, 2+=可叠加效果层数（上限 3）
    # }

    # === 职业资源 ===
    class_resources: dict[str, ResourceState]
    # 资源键 → ResourceState
    # ResourceState = {
    #   current: int,            # 当前剩余
    #   max: int,                # 最大值
    #   recovery: str,           # "short_rest" / "long_rest" / "dawn"
    # }
    # 示例:
    #   "rage_charge": {current: 2, max: 2, recovery: "long_rest"}
    #   "ki_point":    {current: 4, max: 4, recovery: "short_rest"}
    #   "second_wind": {current: 1, max: 1, recovery: "short_rest"}

    # --- read API ---
    def get_modifier(self, stat: str) -> int: ...
    def get_skill_bonus(self, skill: str) -> int: ...
    def get_inventory_by_tag(self, tag: str) -> list[ItemStack]: ...
    def get_equipped(self, slot: str) -> Item | None: ...
    def get_item_count(self, item_id: str) -> int: ...  # 查询持有数量

    # 法术 read
    def get_spell_slots(self, level: int) -> SpellSlotState | None: ...
    def has_spell_slot(self, level: int) -> bool: ...
    def get_lowest_available_slot(self, min_level: int) -> int | None:
        """找最低可用法术位 >= min_level（升槽 UI 用）"""
    def is_spell_prepared(self, spell_id: str) -> bool: ...

    # 状态效果 read
    def get_active_effects(self) -> list[ActiveEffect]: ...
    def has_effect(self, effect_id: str) -> bool: ...
    def get_effect_modifiers(self) -> dict[str, int]:
        """聚合所有活跃效果修正: {ac: -2, attack: -1, speed: -2, ...}"""
    def is_action_prevented(self) -> bool:
        """任何 prevents_action=true 的效果？（眩晕等）"""
    def get_disadvantage_checks(self) -> list[str]:
        """返回有劣势的检定类型列表"""
    def get_advantage_on_attacks_against(self) -> bool:
        """攻击此目标是否有优势（致盲/束缚/俯卧近战）"""

    # 职业资源 read
    def get_resource(self, key: str) -> ResourceState | None: ...
    def has_resource(self, key: str, amount: int = 1) -> bool: ...

    # --- write API ---
    def modify_hp(self, delta: int): ...
    def add_xp(self, amount: int) -> bool: ...  # 返回是否升级
    def modify_gold(self, delta: int): ...
    def add_item(self, item_id: str, count: int = 1): ...
        # 查找已有 ItemStack → 合并（不超过 max_stack）→ 溢出或不存在 → 新建
    def remove_item(self, item_id: str, count: int = 1): ...
        # 减少 count → 0 时移除 ItemStack
    def equip(self, item_id: str, slot: str): ...
    def unequip(self, slot: str): ...

    # 法术 write
    def consume_spell_slot(self, level: int): ...
    def restore_spell_slots(self, level: int | None = None):
        """level=None → 全部恢复到 max"""
    def set_prepared_spells(self, spell_ids: list[str]): ...
    def learn_spell(self, spell_id: str): ...

    # 专注 write
    def set_concentration(self, conc: ActiveConcentration | None): ...
    def break_concentration(self) -> list[str]:

    # 状态效果 write
    def add_effect(self, effect: ActiveEffect) -> str:
        """添加状态效果。返回 instance_id。叠加逻辑:

    def remove_effect(self, instance_id: str): ...
    def remove_effects_by_id(self, effect_id: str): ...
    def tick_effect_durations(self) -> list[str]:
        """所有效果 duration -1。返回过期的 instance_id 列表"""

    # 职业资源 write
    def consume_resource(self, key: str, amount: int = 1): ...
    def restore_resource(self, key: str, amount: int | None = None): ...
    def restore_resources_by_recovery(self, recovery_type: str):
        """恢复所有匹配 recovery 类型的资源（short_rest/long_rest）"""
```

```python
class RelationSlice(StateSlice):
```

**关系质变条件**（来自玩法设计 §三H.6）：

| 转换 | 条件 |
|------|------|
| 陌生人 → 相识 | approval > 10 且有过 1+ 次对话 |
| 相识 → 朋友 | approval > 30 且 trust > 20 且 3+ 次共同经历 |
| 朋友 → 挚友 | trust > 60 且 1+ 次危机选择 且 10+ 次共同经历 |
| 挚友 → 灵魂伴侣 | trust > 80 且 romance > 70 且特殊事件触发 |

### 3.4 QuestSlice — 里程碑 + 动态任务

> **双区模型**：里程碑状态（对应 ❶ QuestRegistry 的 StoryMilestone）+ 动态任务（NarrativePlanner 运行时生成）。

```python
class QuestSlice(StateSlice):

    # DynamicQuest = {
    #   id: str,                   # NarrativePlanner 生成的唯一 ID
    #   title: str,
    #   target_milestone: str,     # 对应的里程碑 ID
```

## 五、权限模型

L2（SessionRuntime）根据调用者角色暴露不同的切片访问：

| 调用者 | 可读切片 | 可写切片 |
|--------|---------|---------|
| **引擎**（pre-tick） | 全部 | 全部 |
| **AI Osiris**（通过引擎间接） | 全部（snapshot） | Flag / Relation / Quest / Area / Event（通过指令） |
| **GM Agent** | 全部 | **无**（纯只读） |
| **NPC Agent** | Scene + 自身 Relation + Flag | Relation（仅自身好感度）+ Scene |
| **队友 Agent** | Scene + 自身 Party + Flag | Scene + Party（仅自身审批值相关） |

GM 的零写入权限是架构的硬约束（P2：先执行后展示）。

## 六、持久化策略

### 6.1 本地优先 + 云端异步同步

对齐 BG3 存档模式——本地即时保存，云端是备份/跨设备同步。

```
SaveStore（存档管理器）
    │
    ├─ 本地存档（主存储，同步写入，零延迟）
    │   saves/{session_id}/
    │       ├─ state/time.json        ← TimeSlice
    │       ├─ state/player.json      ← PlayerSlice
    │       ├─ state/relations.json   ← RelationSlice
    │       ├─ state/quests.json      ← QuestSlice
    │       ├─ state/flags.json       ← FlagSlice
    │       ├─ state/areas.json       ← AreaSlice
    │       ├─ state/events.json      ← EventSlice
    │       ├─ state/party.json       ← PartySlice
    │       ├─ meta.json              ← 存档元数据
    │       └─ (scene 不持久化——格级生命周期)
    │
    └─ 云端存档（备份，异步上传，不阻塞游戏）
        Firestore: worlds/{world_id}/sessions/{session_id}/state/*
```

### 6.2 Dirty Tracking

每个切片内部维护 `_dirty: bool` 标记。`persist()` 时只写 dirty 切片，减少 I/O。

### 6.3 恢复流程

```
SaveStore.load(session_id)
    → 优先读取本地存档 saves/{session_id}/state/
    → 本地不存在时回退到 Firestore 云端存档
    → StateContainer.restore(data)
    → 每个切片各自 restore 自己的部分
```

### 6.4 云端同步策略

| 场景 | 行为 |
|------|------|
| 每次动作后 | 本地写入 + 标记 cloud pending |
| 格结算后 | 本地写入 + 立即云端同步（重要节点） |
| 玩家主动保存 | 本地写入 + 立即云端同步 |
| 后台定时 | 批量上传 pending（每 30 秒） |
| 网络不可用 | 本地正常运行，恢复后自动同步 |
| 跨设备恢复 | 从云端下载到本地，以时间戳较新者为准 |
