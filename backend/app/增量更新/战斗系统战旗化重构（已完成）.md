## 一、现状分析

### 1.1 当前战斗系统画像

`combat.py`（1296 行）实现了一套**无空间、玩家先手、原子回合制**战斗：

| 维度 | 现状 | 目标 |
|------|------|------|
| 空间模型 | **无** — 零坐标、零距离检查 | 正方格网格 + 地形 |
| 回合结构 | 玩家行动 → 所有怪物原子反击 | 速度制交替行动（先攻队列） |
| 行动经济 | 1 action = 全回合 | 移动 + 行动 分离 |
| 参战单位 | 仅玩家 vs 怪物 | 玩家 + 队友 vs 怪物（3v5） |
| 怪物 AI | 2 种性格决策树（attack/flee） | 规则 AI（A* + 地形）+ 精英 LLM |
| 地形效果 | 无 | 8 种地形 + 全局环境 |
| 远程/近战 | `attacks[].range` 存在但**不做距离检查** | 距离决定可否攻击 |

### 1.2 可复用的模块

以下核心逻辑可在重构中保留：

| 模块 | 位置 | 复用方式 |
|------|------|---------|
| d20 攻击判定 | `_roll_monster_attack`, `_compute_attack_resolution` | 命中公式沿用（d20 + mod + prof vs AC） |
| 伤害减免链 | `_apply_player_damage_resistance` | resistance/immunity/vulnerability 直接复用 |
| 状态效果系统 | `status_effect.py` + `active_effects` | 效果结构 + tick 逻辑完整 |
| 怪物模板数据 | `monsters.json` | attacks 已有 range/damage_dice/tags |
| XP 结算 | `_compute_combat_xp` | 击杀 XP 计算直接复用 |
| dice 工具 | `skill_check.py` 的 `resolve_roll` | d20 + 优劣势完整 |

### 1.3 必须重写的部分

| 模块 | 原因 |
|------|------|
| 回合控制流 | 从"玩家→全怪物"改为先攻队列逐单位行动 |
| `start_combat` | 需初始化网格、放置单位、生成先攻序 |
| `_resolve_monster_responses` | 拆解为单怪物回合（含移动+行动） |
| `advance_combat_round` | 改为推进先攻队列中的下一个单位 |
| 所有 player_flags 逻辑 | defending/disengaged/dashed 改为 per-unit 状态 |

### 2.5 先攻（Initiative）系统

```python
def roll_initiative(unit: dict) -> int:
    """d20 + DEX modifier。速度制交替行动。"""
    dex_mod = (unit["stats"]["dex"] - 10) // 2
    roll = random.randint(1, 20)
    return roll + dex_mod

def build_turn_order(units: list[dict]) -> list[str]:
    """按先攻值降序排列所有存活单位。同值时 DEX 高者优先。"""
    initiatives = []
    for u in units:
        if u["alive"] and not u["fled"]:
            init_val = roll_initiative(u)
            initiatives.append((init_val, u["stats"]["dex"], u["unit_id"]))
    initiatives.sort(key=lambda x: (x[0], x[1]), reverse=True)
    return [uid for _, _, uid in initiatives]
```

### 2.8 单回合流程

```
当前单位的回合开始
  │
  ├─ 若为玩家 → 前端展示：可移动范围 + 可用行动
  │   ├─ [可选] combat_move → 移动到目标格
  │   │   └─ 离开敌方近战范围时触发机会攻击（除非本回合已 disengage）
  │   ├─ [必选其一]
  │   │   ├─ combat_attack    — 攻击目标
  │   │   ├─ combat_defend    — 防御（AC+2 到下回合）
  │   │   ├─ combat_disengage — 脱离（本回合移动不触发机会攻击）
  │   │   ├─ combat_dash      — 冲刺（本回合移动力翻倍）
  │   │   ├─ combat_skill     — 使用技能/法术
  │   │   ├─ combat_use_item  — 使用消耗品
  │   │   ├─ combat_shove     — 推撞
  │   │   └─ combat_flee      — 逃跑
  │   └─ combat_end_turn（或行动+移动都用完后自动结束）
  │
  ├─ 若为队友 → engine 触发 combat_npc_turn
  │   └─ LLM 决策（输入：战场状态 + 性格 + 关系）→ 移动 + 行动
  │
  ├─ 若为普通怪 → engine 触发 combat_npc_turn
  │   └─ 规则 AI（A* 寻路 + 地形加权 + 目标选择）→ 移动 + 行动
  │
  └─ 若为精英/BOSS → engine 触发 combat_npc_turn
      └─ LLM 决策（输入：战场状态 + 战术目标）→ 移动 + 行动

回合结束 → 推进 current_turn_index → 若越界则 combat_round++ 并重置 index=0

机会攻击规则：
  - 当一个单位离开敌方的近战范围（曼哈顿距离 1）时触发
  - 敌方可做一次免费近战攻击（不消耗行动）
  - 每个敌方单位每轮只能做一次机会攻击
  - 本回合使用 disengage 的单位不触发机会攻击
  - 单位倒下（hp≤0）时不触发
```

        """BFS：从 start 出发，在 move_points 内可到达的所有格子。"""
        ...

    def shortest_path(

        """A* 寻路。cost = terrain.move_cost。不可穿过敌方单位。"""

        ...

    def cells_in_range(
        self, center: tuple[int, int], range_: int
    ) -> list[tuple[int, int]]:
        """曼哈顿距离 ≤ range 的所有格子。"""
        ...

    def distance(self, a: tuple[int, int], b: tuple[int, int]) -> int:
        """曼哈顿距离 = |dx| + |dy|。"""
        ...

    @classmethod
    def from_map_data(cls, map_data: dict) -> "BattleGrid":
        """从战斗地图 JSON 构建。"""
        terrain = [[ch for ch in row] for row in map_data["terrain"]]

#### 3.5.3 突袭检定深化

**现状**：`HostileAreaHandler.enter_hostile` 做一次隐匿骰（d20 + stealth vs DC），输出二元 surprise_state。

**目标**：升级为 **per-unit 突袭判定**，支持"部分怪物被突袭、部分不被突袭"的细粒度。

```python
# 突袭检定流程（在 start_combat 中执行，而非 enter_hostile）
def resolve_surprise(
    units: list[dict],
    base_surprise_state: str,  # 来自 enter_hostile 的隐匿骰结果
    stealth_total: int,        # 隐匿方的 stealth 骰总值（用于 per-unit 对抗）
) -> list[dict]:
    """
    Per-unit 突袭判定。

    规则：
    - "player_surprise" → 敌方默认全体 surprised=True
      → 但每个敌方单位可骰 d20 + WIS mod 对抗 stealth_total
      → 通过（≥ stealth_total）则该单位 surprised=False（"警觉"）
    - "enemy_surprise" → 友方全体 surprised=True（玩家+队友被突袭，无对抗）
    - "none" → 无人被突袭
    """
    for unit in units:
        if base_surprise_state == "player_surprise" and unit["side"] == "enemy":
            # per-unit 感知对抗
            wis_mod = (unit["stats"].get("wis", 10) - 10) // 2
            perception_roll = random.randint(1, 20) + wis_mod
            unit["surprised"] = perception_roll < stealth_total
        elif base_surprise_state == "enemy_surprise" and unit["side"] == "ally":
            unit["surprised"] = True
        else:
            unit["surprised"] = False
    return units
```

**效果**：BOSS/精英怪物（高 WIS）更难被突袭，普通哥布林（WIS 8, mod=-1）几乎必被突袭。

**Surprise Round（第0轮）强制执行**：
```python
# combat_npc_turn / combat_attack 中检查
if payload["combat_round"] == 0 and unit["surprised"]:
    # 被突袭的单位在第 0 轮不能行动
    # 自动 skip → end_turn
    return skip_turn_result(unit)

# 第 0 轮结束后，清除所有 surprised 标记
if new_round == 1:
    for u in payload["units"]:
        u["surprised"] = False
```

**unit 新增字段**：
```python

    "surprised": bool,  # 第 0 轮是否被突袭（第 1 轮起自动清除）
}
```

#### 3.5.4 先攻检定

**现状**：完全缺失。

**目标**：`start_combat` 时为每个单位掷先攻（d20 + DEX mod），生成 `turn_order`。

```python
def roll_initiative(unit: dict) -> tuple[int, int]:
    """
    Returns (initiative_total, dex_score) for tiebreaking.
    initiative = d20 + (dex - 10) // 2
    """
    dex = unit["stats"].get("dex", 10)
    dex_mod = (dex - 10) // 2
    roll = random.randint(1, 20)
    return (roll + dex_mod, dex)

def build_turn_order(units: list[dict]) -> tuple[list[str], dict[str, int]]:
    """
    为所有存活单位掷先攻，返回 (排序后的 unit_id 列表, {unit_id: initiative_total})。
    排序：initiative 降序，同值 DEX 高者优先，再同值随机。
    """
    rolls = {}
    for u in units:
        if u["alive"] and not u["fled"]:
            total, dex = roll_initiative(u)
            rolls[u["unit_id"]] = total

    sorted_ids = sorted(
        rolls.keys(),
        key=lambda uid: (rolls[uid], next(u["stats"]["dex"] for u in units if u["unit_id"] == uid)),
        reverse=True
    )
    return sorted_ids, rolls
```

**先攻结果存储**：

    assert unit["unit_id"] == payload["current_unit_id"]

    grid = BattleGrid.from_payload(payload["grid"])
    reachable = grid.reachable_cells(unit["position"], unit["speed"], payload["units"])
    assert target in reachable
    unit["position"] = list(target)
    unit["move_used"] = True
    # 返回 StateChange

def _compute_combat_end_turn(self, state, world, params):
    idx = payload["current_turn_index"] + 1
    if idx >= len(payload["turn_order"]):
        idx = 0
        payload["combat_round"] += 1
    # 跳过死亡/逃跑单位
    while not is_active(find_unit(payload, payload["turn_order"][idx])):
        idx = (idx + 1) % len(payload["turn_order"])
    payload["current_turn_index"] = idx
    payload["current_unit_id"] = payload["turn_order"][idx]
    new_unit = find_unit(payload, payload["current_unit_id"])
    new_unit["action_used"] = False
    new_unit["move_used"] = False
    # 返回 StateChange

**队友倒下处理**：
- `alive=False` → 跳过回合 → 战斗结束后不影响 PartySlice
- 不永久死亡

**测试**：
- 队友出现在 units 列表中（side=ally, source=companion）
- LLM 返回合法行动时执行成功
- LLM 返回非法行动时 fallback 规则 AI
- LLM 失败时 fallback 规则 AI
- 队友倒下后被跳过

## 七、风险与约束

### 7.1 兼容性风险

- **旧存档**：旧战斗 payload 无 grid/units → 需要版本标记 + 旧逻辑暂时保留（Phase 2 兼容期，Phase 8 清理）
- **前端同步**：后端 payload 变化需前端配合（SSE 事件格式全变）→ 建议后端先做完，前端再适配
- **45 个旧测试**：大部分需要重写（payload 格式变了）→ 每个 Phase 同步更新测试

### 7.2 性能考量

- A* 寻路在 8×6 网格上 < 1ms，无性能问题
- 每轮 2-3 次 LLM 调用（队友 + 可能的精英怪）→ 与现有对话系统同量级
- BFS 可达性计算同理，8×6 网格开销忽略不计

| Phase | 内容 | 预估新增/修改行数 | 预估测试数 |

## 八、已确认的设计决策

| # | 问题 | 决策 |
|---|------|------|
| 1 | 队友 combat_stats 数据源 | **手写**，直接在 characters.json 中填写 |
| 2 | AoE / 法术系统 | **本次不做**，作为后续 Phase |
| 3 | 机会攻击 | **做**。离开敌方近战范围触发，disengage 行动可免除，每单位每轮限一次 |
| 4 | defend/disengage/dash | **全保留**。完整 D&D 5e 简化版行动列表 |
| 5 | per-unit 突袭对抗 | **做**。被突袭方每个单位骰 d20+WIS mod 对抗 stealth_total，高感知者可免除突袭 |
| 6 | planted 遭遇可见性 | **先感知检定**。passive_perception vs encounter_dc，通过则提示"前方有危险"可选绕行，失败则直接 spotted |
| 7 | 地图数量 | **先做 3-5 类核心地图**（cave/ruins/plains/woodland/hills），全 10 类下一轮补齐 |

- **战斗中存档** — 战斗状态完全在 hostile_tracking 中，存档/读档天然支持，需确认前端是否需要特殊处理
