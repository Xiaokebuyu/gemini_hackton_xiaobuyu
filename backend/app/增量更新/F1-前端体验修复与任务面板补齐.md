# F1 - 前端体验修复与任务面板补齐

日期：2026-03-05
性质：Bug 修复 + 功能补齐（临时性修补，非架构重构）

---

## 修改总览

本次修改解决了实际测试中发现的 4 个问题：

| # | 问题 | 根因 | 修复方式 |
|---|------|------|----------|
| 1 | AI 生成的图片不显示 | Vite 代理只转发 `/api`，图片 URL `/static/images/...` 未被代理 | 添加 `/static` 代理规则 |
| 2 | 任务面板不显示里程碑 | 后端返回的 milestone_states 缺 title/description；前端未渲染 | 后端合入内容层标题；前端添加里程碑渲染 |
| 3 | 玩家手动输入文字不会被 LLM 收到 | 自由文字统一走 `/input/stream`（只识别命令别名），对话文字被拒绝 | 对话上下文中路由到 `/interact/stream` |
| 4 | 进入 NPC 对话后无退出按钮 | 选项列表中缺少"结束对话"选项 | 添加退出按钮，从 lastOverview 重建探索选项 |

附带调整：非激活角色立绘透明度从 `opacity-40` 改为 `opacity-100`（用户要求完全不透明）。

---

## 详细修改记录

### 1. 图片代理修复

**文件**：`frontend/vite.config.ts`

- 添加 `/static` 代理规则到 Vite dev server，与 `/api` 同样指向 `http://localhost:8000`
- 后端通过 `StaticFiles` 挂载 `data/cache/images/` 到 `/static/images/`，前端需要代理才能访问

### 2. 任务面板里程碑显示

**文件**：
- `backend/app/routers/panels.py` — `_quest_response()` 方法
- `frontend/src/game/overlays/QuestPanel.tsx`

**后端改动**：
- `_quest_response()` 不再原样透传 `milestone_states`
- 遍历每个 milestone，从内容层 `QuestRegistry.get_milestone()` 获取 `MilestoneTemplate` 的 title/description/chapter_id，合入返回数据

**前端改动**：
- 新增 `MilestoneStatus` 类型及对应的图标/标签映射
- 新增 `msStatus()` 解析函数
- 过滤掉 `LOCKED` 状态的里程碑，在主线进度和动态任务之间渲染非锁定里程碑
- 更新 `hasContent` 判断逻辑包含 milestones

### 3. 玩家自由文字输入路由修复

**文件**：
- `frontend/src/stores/optionStore.ts`
- `frontend/src/hooks/useGameStream.ts`
- `frontend/src/game/OptionPanel.tsx`
- `frontend/src/game/DialogueArea.tsx`
- `frontend/src/pages/GamePage.tsx`

**核心逻辑**：
- `optionStore` 新增 `talkTargetNpcId: string | null` 状态
- `setFromDialogueOptions()` 接受第三个参数 `npcId`，在 `dialogue_options` 和 `talk_snapshot` SSE 事件处理时传入
- `OptionPanel.handleSend()` 检测对话上下文：
  - 有 `talkTargetNpcId` -> 走 `sendInteract`（发到 `/interact/stream`，LLM 处理）
  - 无 -> 走 `sendInput`（发到 `/input/stream`，命令解析）
- 输入框 placeholder 随上下文切换："输入你想说的话..." vs "输入你想做的事..."
- `sendInteract` prop 从 GamePage -> DialogueArea -> OptionPanel 透传

### 4. 对话退出按钮

**文件**：
- `frontend/src/stores/sceneStore.ts`
- `frontend/src/game/OptionPanel.tsx`
- `frontend/src/game/DialogueArea.tsx`
- `frontend/src/pages/GamePage.tsx`

**核心逻辑**：
- `sceneStore` 新增 `lastOverview: LocationOverview | null`，在 `updateFromOverview()` 时缓存
- `OptionPanel` 在对话上下文中（`talkTargetNpcId` 非空时）显示"结束对话"按钮
- 点击后调用 `onLeaveDialogue` 回调：清空对话选项 -> 从 `lastOverview` 重建探索选项
- `onLeaveDialogue` 在 GamePage 中实现（`handleLeaveDialogue`），调用 `optionStore.clearOptions()` + `optionStore.buildFromOverview(lastOverview, overviewHandlers)`

### 5. 立绘透明度调整

**文件**：`frontend/src/game/Portrait.tsx`

- 非激活角色：`opacity-40 scale-95` -> `opacity-100 scale-95`

## 已知局限

1. **自由文字路由是前端 heuristic**：通过 `talkTargetNpcId` 判断对话上下文，如果 SSE 未携带 `npc_id`（某些边缘路径），可能回退到命令解析模式
2. **结束对话从 lastOverview 重建**：如果在对话期间场景状态发生变化（NPC 移动、新事件），重建的选项可能过时（需等下次流刷新）
3. **`/input/stream` 仍只支持命令别名**：非对话上下文的自由文字（如 "search the room"）仍会被拒绝，InputPort 未扩展
4. **里程碑渲染只过滤 LOCKED**：FAILED 状态的里程碑也会显示，是否合理取决于设计意图
