### 1.4 索引维护（去索引闭环）

必须在写入、替换、删除三个路径同时覆盖。

**`add_node()` 替换分支**：先去旧索引再加新索引

```python
if existed_before:
    old_node = self.get_node(node.id)
    if old_node:
        self._type_index.get(old_node.type, set()).discard(node.id)
        if old_node.name:
            self._name_index.get(old_node.name.lower(), set()).discard(node.id)
        old_day = old_node.properties.get("day") or old_node.properties.get("game_day")
        if old_day is not None:
            self._day_index.get(int(old_day), set()).discard(node.id)
        for pid in old_node.properties.get("participants", []):
            self._participant_index.get(pid, set()).discard(node.id)
        old_owner = old_node.properties.get("owner")
        if old_owner:
            self._owner_index.get(old_owner, set()).discard(node.id)
```

**`add_node()` 新索引写入**（新建和替换都走）：

```python
if node.name:
    self._name_index[node.name.lower()].add(node.id)
day = node.properties.get("day") or node.properties.get("game_day")
if day is not None:
    self._day_index[int(day)].add(node.id)
for pid in node.properties.get("participants", []):
    self._participant_index[pid].add(node.id)
owner = node.properties.get("owner")
if owner:
    self._owner_index[owner].add(node.id)
```

**`_deindex_node(nid)`**：新增 5 个索引清理（同上逻辑取反）。

**边删除**：`_edge_id_index` 的 `del` 操作。

**`add_edge()`**：维护 `_edge_id_index[key] = (source, target, key)`。

### 1.5 新增 7 个查询方法

def recall(
    self,
    world_graph: WorldGraph,
    character_id: str,
    seed_nodes: List[str],

    cfg = RECALL_CONFIGS.get(intent_type or "", {})

        output_threshold=cfg.get("output_threshold", 0.15),

### 4.2 RecallOrchestrator.recall_for_role()

> 分层标记：本阶段只保留“可运行的最小角色种子策略”；最终角色可见性与策略矩阵后置到 L2。

```python
def recall_for_role(
    self,
    world_graph: WorldGraph,
    role: str,
    character_id: str,
    seed_nodes: List[str],
    intent_type: str = None,
) -> RecallResponse:
    if role == "npc":
        # 从 NPC 自身出发，个人记忆优先
        seeds = [character_id] + seed_nodes
    elif role == "teammate":
        # 从 NPC 自身 + camp 出发
        seeds = [character_id, "camp"] + seed_nodes
    elif role == "gm":
        # 从区域出发，全局视角
        area_nodes = world_graph.get_by_type("area")
        seeds = seed_nodes  # GM 不限定起点
    else:
        seeds = seed_nodes

    return self.recall(world_graph, character_id, seeds, intent_type)
```

async def _restore_world_graph_snapshot(self) -> None:
