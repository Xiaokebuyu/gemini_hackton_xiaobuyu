# 任务系统

## 模块概要

双轨任务系统：静态里程碑（内容层预设）+ 动态任务（Planner 运行时创建）。三层自动完成机制。

### 核心模块

| 模块 | 位置 | 职责 |
|------|------|------|
| QuestSlice | `state/slices/quests.py` | 任务状态：milestone_states（静态里程碑状态机）+ dynamic_quests（运行时创建的任务） |
| QuestRegistry | `content/registries/quests.py` | 静态任务/里程碑模板（章节、完成条件、奖励、next_milestones 级联） |
| ReceptionistHandler | `rules/handlers/receptionist.py` | 柜台小姐任务接受/汇报机制 |
| BoardHandler | `rules/handlers/board.py` | 任务板浏览/接受/完成/退回 |

### 自动完成三层机制

| Hook | priority | 职责 |
|------|----------|------|
| MilestoneCompletionHook | 54 | 静态里程碑条件满足 → 自动 COMPLETED |
| MilestoneUnlockHook | 55 | 里程碑完成 → 级联解锁 next_milestones |
| QuestObjectiveTrackingHook | 56 | 动态任务 objective.condition 自动检测（11 种条件类型） |
| TaskMonitorHook | 57 | quest.task_monitor.conditions 全满足 → auto/notify |
| QuestExpiryHook | — | 过期动态任务自动退役 |

### 11 种任务完成条件

flag_set, npc_talked, item_obtained, kill_count, level_reached, location_visited, encounter_cleared, clue_investigated, all_encounters_cleared, danger_below, location_entered

### 辅助模块

| 模块 | 位置 | 职责 |
|------|------|------|
| quest_views | `app/quest_views.py` | 任务面板 API payload 构建 |
| service_effect | `rules/handlers/service_effect.py` | 任务奖励的原子效果执行（金币/XP/物品） |
