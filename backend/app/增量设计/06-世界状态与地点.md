# 世界状态与地点

## 模块概要

三层嵌套地点系统（area → sub_location → room），动态子区域/房间生成，NPC 调度与在场性。

### 核心模块

| 模块 | 位置 | 职责 |
|------|------|------|
| AreaSlice | `state/slices/area.py` | 区域运行时状态：temporary_sub_areas、dynamic_rooms、hostile_tracking、interactable_states、area_situation、area_events、scoped_interactable_overlays |
| MapRegistry | `content/registries/maps.py` | 静态地图模板：area → sub_location → room 结构 |
| NavigationHandler | `rules/handlers/navigation.py` | 区域/位置移动校验与执行 |
| NpcScheduleHook | `orchestration/hooks/npc_schedule.py` | NPC 定时位置转移（directive destination 优先 → character schedule → 全局规则 fallback） |
| PresenceModule | `orchestration/presence.py` | NPC 在场性查询（area/location/room 可达性） |

### 动态地点生成

| 能力 | 对应 directive | Handler |
|------|---------------|---------|
| 新建子区域 | fill_area | planner_fill_area |
| 新建房间 | fill_room | planner_fill_room |
| 解锁隐藏房间 | discover_room | planner_discover_room |
| 场景内放置 interactable | fill_location | planner_fill_location |
| 环境线索/子区域 | plant_environmental | planner_plant_environmental |
| 种植遭遇 | plant_encounter | planner_plant_encounter |

### 辅助模块

| 模块 | 位置 | 职责 |
|------|------|------|
| DynamicSubAreaManager | `planning/dynamic_sub_area.py` | 动态子区域创建/过期/容量管理 |
| DynamicSubAreaExpiryHook | `orchestration/hooks/dynamic_sub_area_expiry.py` | 过期动态子区域清理 |
| AIOsirisHook | `orchestration/hooks/ai_osiris.py` | 机械因果引擎：规则表驱动（set_flag + adjust_danger），协调 EncounterHook + PassivePerceptionHook + EventConditionHook |
| MechanicalOsirisEngine | `orchestration/hooks/ai_osiris.py` | 纯规则表驱动的因果引擎（已去 LLM） |
| WorldStateHandler | `rules/handlers/world_state.py` | 世界属性修改（set_flag, adjust_danger, modify_disposition, advance_quest 等） |
| EventEngine | `orchestration/event_engine.py` | 事件条件评估核心（BasicEventConditionEvaluator，12+ 种条件类型） |
| scene_views | `app/scene_views.py` | 场景状态 API payload 构建 |
| location_utils | `game_core/location_utils.py` | 地点归一化和匹配工具 |
