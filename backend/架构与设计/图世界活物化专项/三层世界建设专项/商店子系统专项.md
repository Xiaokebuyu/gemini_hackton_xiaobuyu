## 一、设计目标

**混合商店模式**：结构化商店面板（玩家自助浏览/购买/出售）+ NPC 老板交互（对话影响价格/解锁隐藏商品/讨价还价）。

两条路径共享同一个底层 ShopEngine：
- **REST API 路径**：前端商店面板 → REST 端点 → SessionRuntime → ShopEngine
- **NPC 对话路径**：`/interact/stream` → NPC Agent + merchant 工具 → SessionRuntime → ShopEngine

### 1.1 与物品子系统的关系

商店系统是物品子系统的**消费方**之一。依赖关系：

```
物品子系统（基础设施）
  A. 物品注册表 ──→ 商店读取物品定义 + 价格
  B. 背包系统   ──→ 商店写入购买物品 / 读取出售物品
  金币系统      ──→ 商店扣除/增加金币
```

物品注册表、背包、装备、物品效果的详细设计见 [物品子系统专项](物品子系统专项.md)。

### 4.2 traits 缺失问题

WorldGraph 中 **1453 个节点中 0 个有 traits**。`pipeline_orchestrator.py:766` 读取 `npc_node.properties.get("traits", [])` 始终返回空集，导致 merchant/guard/quest_giver/healer 等 trait 工具**永远不会激活**。

**D4 决策**：留接口等管线。traits 枚举表：

| trait | 说明 | 激活的工具 | 适用 NPC |
|-------|------|-----------|---------|
| merchant | 商人 | sell_to_customer, buy_from_customer, show_my_inventory, adjust_my_prices | forge_master, seamstress |
| guard | 守卫 | grant_passage | 城门卫兵 |
| quest_giver | 任务发布者 | offer_quest | guild_girl |
| healer | 治疗者 | offer_healing | 神官 |

### 4.3 NPC → 商店映射

商人 NPC 通过 `resident_npcs` 关联到 shop 子地点：

```
NPC agent_id (e.g. "forge_master")
  → maps.json sub_locations: 找 resident_npcs 包含该 NPC 且 interaction_type="shop"
  → shop_id (e.g. "blacksmith_workshop")
  → shop_stock config
```

```
┌─────────────────────────────────────────────────────────┐
│ 顶层: 商店 REST API + 商人沉浸式工具                       │
│   REST: GET .../shop/inventory, POST .../shop/buy|sell  │

│   get_shop_inventory(shop_id, category?)                │
│   get_shop_info(shop_id)                                │
├─────────────────────────────────────────────────────────┤
│ 底层: ShopEngine (纯机械，零 LLM/IO)                      │
│   get_shop_stock() · calculate_buy/sell_price()         │
│   validate_purchase() · execute_purchase/sale()         │
│   clamp_price_modifier()                                │
├─────────────────────────────────────────────────────────┤
│ 数据依赖                                                  │
│   ← 物品子系统: ItemRegistry（物品定义+价格）+ 背包（物品流转）│
│   ← maps.json: shop_stock 配置                           │
│   ← TimeManager: 营业时间                                 │
│   ← WorldGraph: NPC disposition（好感度 → 价格倍率）       │
└─────────────────────────────────────────────────────────┘
```

### 5.1 数据流：购买物品

**REST API 路径**（结构化面板）：
```
POST /api/game/{world_id}/sessions/{session_id}/shop/buy
  body: { shop_id, item_id, quantity }
    ↓
AdminCoordinator → SessionRuntime.buy_item(shop_id, item_id, qty)
    ↓
SessionRuntime:
  1. shop_config = WorldInstance maps → shop_stock
  2. is_shop_open()? → 营业校验
  3. item = ItemRegistry.get_item(item_id) → 物品存在 + 价格
  4. price = ShopEngine.calculate_buy_price(base_price, modifier)
  5. ShopEngine.validate_purchase(player.gold, price, qty) → 余额校验
  6. stats_manager.remove_gold() + player.add_item() → 执行
  7. mark_player_dirty()
```

**NPC 对话路径**（沉浸式交互）：
```
/interact/stream → NPC Agent (traits={"merchant"})
    ↓
NPC 调用 sell_to_customer(item_id="armor_leather", quantity=1)
    ↓
sell_to_customer 工具:
  1. shop_id = _resolve_shop_id(ctx) → 从 NPC ID 找到所属商店
  2. ctx.session.buy_item(shop_id, item_id, qty) → 同上逻辑
  3. return 交易结果 → NPC 据此叙述
```

## 六、设计决策

### D1: 商店库存方案 ✅

**方案 A**：`maps.json` 子地点扩展 `shop_stock`，按品类过滤 ItemRegistry。商人位置固定，商店与地点天然绑定。

### D2: 价格体系 ✅

- **内部单位：银币（sp）**，通过汇率表 `CURRENCY_RATES` 统一换算
- **好感度折扣：NPC 自由裁定**，引擎限制范围 0.7~1.3。NPC Agent 通过 `adjust_my_prices` 工具调价
- **出售折扣率：50%**（D&D 标准）

### D4: NPC traits ✅

留接口 + 文档，等管线更新时统一填充。接口已就绪（`pipeline_orchestrator.py:766`）。

### D5: 商人工具 ✅

**双路径**，删除 evaluate_offer/propose_deal，新建/重写 4 个工具：

| 工具 | 说明 | 底层调用 |
|------|------|---------|
| `show_my_inventory(category?)` | 展示货架 | session.get_shop_inventory() |
| `sell_to_customer(item_id, qty, discount_percent?)` | NPC 卖给玩家 | session.buy_item() |
| `buy_from_customer(item_id, qty)` | NPC 从玩家购买 | session.sell_item() |
| `adjust_my_prices(discount_percent, reason)` | NPC 临时调价（0.7~1.3） | ShopEngine.clamp → 会话状态 |

### D6: REST API ✅

CRPG 级前端体验，独立商店页面：

```
GET  .../shop/inventory   商店货架 + 价格 + 可购买状态
POST .../shop/buy         购买物品
POST .../shop/sell        出售物品
GET  .../shop/info        商店元信息
```

背包/装备 REST API 见 [物品子系统专项](物品子系统专项.md)。

def _resolve_shop_id(ctx: AgenticContext) -> Optional[str]:
    npc_id = ctx.agent_id
    for sub_loc in ctx.session.get_sub_locations():
        if sub_loc.get("interaction_type") == "shop" and npc_id in sub_loc.get("resident_npcs", []):
            return sub_loc["id"]
    return None
