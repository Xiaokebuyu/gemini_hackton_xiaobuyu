# 玩家状态与经济

## 模块概要

玩家核心状态（身份/属性/HP/金币/库存/装备）、经济交易、角色成长、休息恢复、同伴入队。

### 核心状态：PlayerSlice

位置：`state/slices/player.py`

| 域 | 字段 | 说明 |
|----|------|------|
| 身份 | character_id, character_name, character_class, subclass, guild_rank, guild_reputation | 角色基础身份 |
| 属性 | stats{str/dex/con/int/wis/cha}, proficiency_bonus | D&D 六维 + 熟练加值 |
| 等级 | level, xp, asi_points_remaining, class_features | 等级/经验/ASI 点数/职业特性 |
| 生命 | hp, max_hp, ac | 血量 + 护甲 |
| 经济 | gold | 金币（整数） |
| 位置 | current_area, current_location, current_room | 三层定位 |
| 库存 | inventory: list[ItemStack(item_id, count, tags)] | 堆叠物品列表 |
| 装备 | equipment: 13 个槽位（head/chest/gloves/boots/cloak/amulet/ring_l/ring_r/main_hand/off_hand/ranged/ammo/belt） | 槽位→物品映射 |
| 魔法 | spell_slots, known_spells, prepared_spells, concentration | 法术槽/已知/准备/专注（战斗搁置，但数据结构已有） |
| 效果 | active_effects, save_proficiencies | 状态效果/豁免熟练 |
| 资源 | class_resources: {key: {current, max, recovery}} | 职业资源（如气、怒气） |

## 各 Handler 当前能力

### InventoryHandler（6 命令）

- **pick_up**：物品入库（合并同 item_id 堆叠 + tags 合并）
- **drop**：物品移除（扣减 count，归零删除）
- **equip**：装备到槽位（校验 slot 合法 + item_type↔slot 约束 + 自动重算 AC）
- **unequip**：卸下装备（清空槽位 + 重算 AC）
- **use_item**：使用消耗品，两条路径：
  - heal 路径：读 item_template.consumable_data.heal_amount → 回血 + 消耗
  - buff 路径：读 effect.type=="buff" + remove_status → 移除指定 active_effect + 消耗
- **consume_resource**：扣减 class_resources（如消耗气点）

AC 重算公式：unarmored=10+DEX, light=base_ac+DEX, medium=base_ac+min(DEX,2), heavy=base_ac, shield 叠加。

### EconomyHandler（3 命令）

- **trade_buy**：从 NPC 商店购买。校验：商人存在 → 商店库存 → 库存充足 → 金币充足。价格 = base_price × sell_markup × approval_discount。
- **trade_sell**：卖给 NPC。价格 = base_price × buy_rate。卖出物品进入商店 buyback 行。
- **refresh_shop**：刷新商店库存。base_pool 保留（restock=false 的保持消耗状态），rotating_pool 按 md5(npc_id:tick) 确定性选取。

好感折扣：approval≥80→70%, ≥50→80%, ≥20→90%, <20→100%。

商店状态存储在 RelationSlice.shop_states（非 PlayerSlice）。

### GrowthHandler（5 命令）

- **create_character**：角色创建全流程。种族 stat_bonuses → 最终属性 → max_hp → ac → starting_gold → class_features（种族+职业+背景）。
- **add_xp**：加经验值，计算可用等级（阈值默认 (level-1)×1000，ClassRegistry 可覆盖）。
- **level_up**：升级。HP 增长 = hp_per_level + CON_mod。获得职业特性。ASI 点数在 4/8/12/16/19 级各 +2。class_resources 按 schema 扩容。
- **apply_asi**：消耗 ASI 点数提升属性（+1 或 +2，上限 20）。
- **choose_subclass**：选择子职业（需达到 class.subclass_level，默认 6 级）。

### RestHandler（4 命令）

- **rest_short**：短休。回 25% max_hp + 恢复 short_rest 类资源 + 移除 cure=short_rest 的效果。time_cost=1.0。
- **rest_long**：长休。回满 HP + 回满法术槽 + 恢复所有资源 + 解除专注 + 移除 cure=long_rest 效果。time_cost=8.0。
- **night_watch**：守夜检定。safe 营地跳过；wilderness 按 danger 定 DC（≤0.5→DC8, ≤1.0→DC12, ≤1.5→DC15, >1.5→DC18），passive perception vs DC。
- **set_camp**：设置营地。写入 area.properties.active_camp。

### CompanionHandler（4 命令）

- **recruit_companion**：招募。校验：NPC 有 "recruitable" tag + 队伍未满（MAX=4）+ 非 stranger + approval>0。招募后写入 PartySlice.members + 设置 npc_presence 到玩家位置。
- **dismiss_companion**：解散。从 PartySlice 移除。
- **force_leave_companion**：强制离队（需 reason 参数）。逻辑同 dismiss。
- **restore_companion_after_combat**：战后恢复同伴 HP（engine/system 专用）。

## 与设计目标的差距

| 设计目标 | 当前状态 | 差距 |
|----------|---------|------|
| 等级上限 5 级 | 无等级上限限制 | 需加 cap 或在 Planner prompt 层控制 |
| 初始属性偏少 | create_character 接受任意 3-20 | 前端/开场序列控制点数池 |
| 升级给属性点玩家自选 | apply_asi 已实现 | ✅ 已有 |
| HP 日常化（采药扣 HP、食物回 HP） | use_item heal 路径已有 | 需要日常物品数据 + Planner 编排日常扣 HP 事件 |
| 食物回 HP | use_item → heal_amount | ✅ 机制已有，需补食物物品数据 |
| 好感折扣 | approval_discount 已实现 | ✅ 已有 |
| 队伍=临时同行 | recruit/dismiss 已有 | 缺"任务完成自动离队"（需 Planner 在剧本末尾 dismiss） |
| 送礼机制 | 无 ReceiveGiftTool | 需新增 NPC agent 工具 |
