# F01 — 前端体验升级

## 背景

后端 P32（Planner 导演模式与冒险体验深化）已完成，游戏机制层面的内容生成能力大幅增强。但前端存在多个体验问题，影响玩家实际感受。

## 问题清单

### 1. 商店面板无法显示

**现状**：当前没有任何手段展示商店/交易面板。玩家无法通过 UI 操作与商人进行买卖。

**预期**：与拥有 `trade_browse` 能力的 NPC 交互时，应弹出商店面板，展示商品列表、价格、购买/出售按钮。

**相关后端接口**：
- NPC 交易通过 `OfferTradeTool` / `SellToPlayerTool` 工具实现
- SSE 事件可能包含交易相关的 payload（如 `trade_offer`、`shop_browse` 等）
- `interaction_views.py` 构建交互响应 payload

### 2. 主画面左上角状态 UI 更新滞后

**现状**：状态面板（可能是玩家信息、HP、金币等）在状态变化后不及时更新。比如完成任务获得奖励后，面板显示的数据还是旧的。

**预期**：每次收到 SSE 事件（`location_overview`、`player_update` 等）后，立即刷新状态面板。

**可能原因**：
- SSE 事件监听器没有触发 UI 重渲染
- 状态管理（store）没有正确响应后端推送的更新
- `location_overview` SSE 事件包含最新的场景快照，前端可能没有消费它

### 3. 导航栏按钮归属不合理

**现状**：各个功能按钮放在了错误的页面/位置上，逻辑归属不对。

**预期**：按钮应按功能归类，放在合理的位置。具体哪些按钮放错了需要调查当前布局后与用户确认。

### 4. UI 整体升级

**现状**：当前 UI 过于简陋/丑陋，不符合 CRPG 游戏的视觉预期。

**预期**：升级为有质感的游戏 UI。参考方向：
- 博德之门 3 / 神界原罪 2 的暗色调 RPG 风格
- 羊皮纸/石材质感的面板背景
- 图标化的按钮和状态指示器
- 合理的信息层级和布局

## 技术栈

- 前端项目路径：`/home/xiaokebuyu/workplace/gemini-hackton/frontend`
- 框架：Vite + TypeScript
- 样式：Tailwind CSS
- 与后端通信：SSE 流式推送（`/api/game/{world}/sessions/{session}/interact/stream` 等）

## 实施建议

1. **先排查商店面板** — 确认后端是否有对应的 SSE 事件和 API，前端是否有但未接入的商店组件
2. **修复状态更新** — 检查 SSE 事件处理链路，确保每次收到状态变更事件后触发 UI 刷新
3. **调整导航布局** — 先截图/录屏当前布局，与用户确认哪些按钮需要移动
4. **UI 风格升级** — 可以分步进行：先换色调和字体，再加材质/纹理，最后细化组件
