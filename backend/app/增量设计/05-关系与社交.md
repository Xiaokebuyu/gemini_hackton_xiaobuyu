# 关系与社交

## 模块概要

NPC 关系系统：好感/信任/恐惧/浪漫四维度，阶段跃迁（stranger→intimate），私聊触发，篝火回忆。

### 核心模块

| 模块 | 位置 | 职责 |
|------|------|------|
| RelationSlice | `state/slices/relations.py` | NPC 关系状态：npc_dispositions（四维度数值）、relationship_stages、npc_blackboards、shop_states |
| PartySlice | `state/slices/party.py` | 队伍成员、同伴好感度（companion_approval） |
| RelationshipHook | `orchestration/hooks/relationship.py` | 关系阶段自动跃迁（stranger→acquaintance→friend→close_friend→intimate + cold→hostile→enemy） |
| PrivateChatTriggerHook | `orchestration/hooks/private_chat_trigger.py` | 休息时检测 romance/trust/intimate 阈值 → "npc_wants_to_chat" SSE |
| PrivateChatCoordinator | `orchestration/private_chat.py` | 私聊 4 步管线（visibility="private" + audience） |
| SharedExperienceHook | `orchestration/hooks/shared_experience.py` | 记录队伍共同经历（战斗/任务/休息） |
| CampfireHook | `orchestration/hooks/campfire.py` | 长休触发篝火对话：经历回忆 + campfire_dialogue SSE + 好感+5 |
| CompanionManager | `orchestration/companion_manager.py` | 同伴招募/解散/强制离队 + hostile 自动解散 |

### 关系阶段

```
正面：stranger → acquaintance(>10) → friend(>30/20) → close_friend(>60 trust) → intimate(>80/60)
负面：任何阶段 → cold → hostile(approval<-50 AND trust<-30) → enemy(trust<-60)
```

### 辅助模块

| 模块 | 位置 | 职责 |
|------|------|------|
| UpdateFeelingTool | `narrative/character_tools.py` | NPC agent 工具：自主调整对玩家的好感/信任/恐惧/浪漫 |
| blackboard_tools | `narrative/blackboard_tools.py` | NPC 黑板自更新（thoughts/goals/observations/mood） |
