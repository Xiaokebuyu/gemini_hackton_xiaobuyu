**严重度**：并发请求导致内存与持久态分叉

`app/services/party_service.py` 所有写操作均为 **先改内存 → 再落库**：

### P1-5: GameRuntime 初始化竞态

**严重度**：并发首次访问同一世界 → 重复初始化

`app/runtime/game_runtime.py:40-49`：
```python
async def get_world(self, world_id: str) -> "WorldInstance":
    if world_id not in self._worlds:          # L44: 无锁检查
        world = WorldInstance(world_id=world_id)
        await world.initialize()              # L46: 异步 I/O，让出控制权
        self._worlds[world_id] = world        # L47: 竞态写入
    return self._worlds[world_id]
```

**竞态序列**：
1. 请求 A 检查 `"world1" not in self._worlds` → True
2. 请求 A `await initialize()` → **让出事件循环**
3. 请求 B 检查 `"world1" not in self._worlds` → **仍然 True**
4. 请求 B 也 `await initialize()` → 两个实例并行初始化
5. 请求 A/B 各自写入 `self._worlds["world1"]` → 后写覆盖先写

**后果**：先完成的 WorldInstance 被覆盖，其引用持有者使用废弃实例。

#### 修复方案

```python
def __init__(self):
    self._worlds: Dict[str, WorldInstance] = {}
    self._world_locks: Dict[str, asyncio.Lock] = {}
    self._meta_lock = asyncio.Lock()

async def get_world(self, world_id: str) -> "WorldInstance":
    if world_id in self._worlds:
        return self._worlds[world_id]
    async with self._meta_lock:
        if world_id not in self._world_locks:
            self._world_locks[world_id] = asyncio.Lock()
    async with self._world_locks[world_id]:
        if world_id not in self._worlds:  # 双检锁
            world = WorldInstance(world_id=world_id)
            await world.initialize()
            self._worlds[world_id] = world
    return self._worlds[world_id]
```

- 工作量：**0.5 天**

```python
    instance.context_window.mark_messages_graphized(message_ids)  # L447
    remove_result = instance.context_window.remove_graphized_messages()  # L448
```

**后果**：
1. 图谱化失败 → 消息未从 ContextWindow 移除
2. 窗口继续增长 → 再次触发图谱化阈值
3. 相同消息再次尝试图谱化 → 再次失败
4. **无限循环**，窗口永远满

#### 修复方案

失败时也应移除消息（或标记为"已尝试"跳过）：
```python
if not result.success:
    # 标记为已尝试，避免反复重试相同消息
    instance.context_window.mark_messages_graphize_failed(message_ids)
    return ...
```

### P2-3: SessionHistory graphize 竞态

**严重度**：并发触发 → 重复图谱化

```python
async def maybe_graphize(self, ...):
    async with self._graphize_lock:
        if self._graphize_in_progress:
            return None
        self._graphize_in_progress = True
    # ... 图谱化逻辑
```
