## 一、目标架构（2026-02-20 提出，已实现）

```
┌─────────────────────────────────────────┐
│  上层：居民（Players / Agents）          │
│  GM Agent / NPC Agent / 队友 Agent / 玩家 │
│  只看到"我能做什么"，通过统一接口行动      │
├─────────────────────────────────────────┤
│  中层：世界规则接口（World API）          │
│  权限控制 / 动作验证 / 结果包装           │
│  对上层暴露统一工具，对下层转发操作         │
├─────────────────────────────────────────┤
│  底层：游戏世界引擎（World Engine MCP）    │
│  WorldGraph + BehaviorEngine + 导航 +     │
│  经济 + 时间 + 事件 + 战斗 + 物品 + ...  │
│  机械真理源，零 AI，纯规则/状态/计算       │
└─────────────────────────────────────────┘
```

## 三、重构前核心问题（全部已修复 ✅）

### 3.1 状态散落（同一数据多处读写）

玩家金币/XP/HP 有 5 条写入路径，每条直接操作 `player.xp`，没有统一校验。
→ ✅ 已通过 StatsManager 纯函数统一收口。

### 3.2 Agent 层和世界层混合

V4AgenticToolRegistry 既是 LLM 工具定义又是状态修改入口；NpcReactor 放在 `app/world/` 但含 LLM 调用。
→ ✅ 已通过沉浸式工具 + RoleRegistry + 底层引擎独立化解决。

### 3.3 三套接口不统一

同一操作（如"给玩家加物品"）有 REST/MCP/V4 Agentic 三条路径，各自校验、各自写入。
→ ✅ 已收敛到 Agentic 工具 → WorldAPI → SessionRuntime 单通道。

### 3.4 缺失的系统

经济/商店/升级/权限系统均不存在。
→ ⏸️ 经济/商店/升级待后续建设。

### 3.5 依赖注入与单例问题

StateManager 三实例分叉、后期注入空指针风险、双重单例冗余。
→ ✅ 已修复（合并为单实例）。

### 3.6 持久化链路脆弱性

Player 唯一持久化路径依赖 WorldGraph 快照；副作用去重不持久化。
→ ✅ 已修复（CharacterStore 兜底 + 脏标记延迟清除 + metadata 持久化去重集）。

### 3.7 私聊系统脱离主管线

`process_private_chat_stream()` 绕过 PipelineOrchestrator。
→ ✅ 已委托 PipelineOrchestrator（D11）。

### 3.8 Firestore 数据模型问题

GameState 多副本无同步、完整 Firestore 路径结构。
→ ✅ StateManager 单实例 + SessionRuntime 统一管理。

## 四、重构方向（已实现）

→ ✅ 通过 SessionRuntime 就地升级实现。

### 上层：居民

每个 Agent 通过 World API 与世界交互。
→ ✅ 通过 AgenticExecutor + RoleRegistry + 沉浸式工具实现。

## 七、数据流全景（重构前快照）

### PipelineOrchestrator.process() 完整调用链

```
玩家输入
  ↓
A 阶段: 上下文组装
  ├── SessionRuntime.restore()
  ├── session.run_behavior_tick("pre")
  ├── IntentResolver.resolve(input)
  │     └── IntentExecutor.dispatch(intent)
  └── NPCReactor.collect_reactions()
  ↓
B 阶段: Agentic 会话
  └── FlashCPUService.agentic_process_v4()
        └── V4AgenticToolRegistry.get_tools()
  ↓
C 阶段: 后处理
  ├── session.run_behavior_tick("post")
  ├── CompanionInstance 事件分发
  ├── TeammateResponseService.process_round()
  └── SessionRuntime.persist()
```

> 注：V4AgenticToolRegistry 已在阶段 4c 删除，替换为 AgenticExecutor + RoleRegistry。
