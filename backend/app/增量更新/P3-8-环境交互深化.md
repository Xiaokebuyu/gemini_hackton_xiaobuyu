## 二、设计要点

### 2.1 被动感知的触发时机

设计文档说"进入新区域时自动被动感知检定"。触发点选择：

| 方案 | 优点 | 缺点 |
|------|------|------|
| A. NavigationHandler 内联 | 语义清晰——进入时立刻检测 | NavigationHandler 变成 god handler |
| B. SettlementHook | 关注点分离——被动感知是独立关切 | 检测延迟到 settlement |
| **C. NavigationHandler 输出 metadata，Hook 消费** | 两层各司其职 | 需要 Hook 读取 pipeline result |

**推荐方案 B**：新建 `PassivePerceptionHook`（settlement hook），检测玩家是否进入了新区域/子地点，对该区域的 discoveries、trap detect_dc、visibility_dc 进行被动感知检定。

理由：
- NavigationHandler 保持单一职责（验证+移动）
- 被动感知是**跨关切**：影响 discoveries、traps、interactables 三类物体
- SettlementHook 的 context 包含完整 state + world，可以做全面检定
- 时序可接受——settlement 紧跟 action 执行后

### 2.2 被动感知计算

```
passive_check = 10 + state.player.get_modifier("wis")
```

D&D 5e 标准公式。PlayerSlice.get_modifier("wis") 已可用。

### 2.3 available_hours 时间映射

TimeSlice 有 `slot`（0-9，对应一天 10 个时段）和 `period`（dawn/day/dusk/night）。

简化映射（不需要精确小时）：
```
period → available_hours 检查：
  dawn  (slot 0-1)  → hour ~= 6-9
  day   (slot 2-5)  → hour ~= 9-18
  dusk  (slot 6-7)  → hour ~= 18-21
  night (slot 8-9)  → hour ~= 21-6
```

available_hours = (8, 20) 意味着 dawn + day + dusk 开放，night 关闭。

**更简洁的方案**：将 available_hours 改为 `available_periods: list[str]`（如 ["day", "dusk"]），避免小时映射的歧义。但这需要改数据格式。

**推荐**：保持 (int, int) 格式，用简单映射：
```python
_PERIOD_HOUR_MID = {"dawn": 7, "day": 13, "dusk": 19, "night": 1}

def _is_location_open(available_hours: tuple[int, int] | None, period: str) -> bool:
    if available_hours is None:
        return True
    start, end = available_hours
    mid_hour = _PERIOD_HOUR_MID.get(period, 12)
    if start <= end:
        return start <= mid_hour < end
    return mid_hour >= start or mid_hour < end  # 跨午夜
```

### Phase 4: InteractableHandler 实装（中）

将 noop 替换为真实实现。支持多检定路径：

```python
def compute(self, cmd, state, world):
    interactable_id = cmd.params["interactable_id"]
    check_index = cmd.params.get("check_index", 0)

    # one_time 检查
    if template.one_time and state.areas.is_interactable_used(area_id, interactable_id):
        return ExecuteResult.error("already_used")

    # 获取选择的检定路径
    check_path = template.checks[check_index]

    # 执行检定
    modifier = state.player.get_skill_bonus(check_path.skill)
    roll, _, dice = resolve_roll()
    total = roll + modifier
    passed = total >= check_path.dc

    if passed:
        # 处理 reward
        if template.one_time:
            state.areas.mark_interactable_used(area_id, interactable_id)
        return handler_success(...)
    else:
        # 处理 fail_consequence（如果有）
        return handler_success(..., metadata={"passed": False})
```
