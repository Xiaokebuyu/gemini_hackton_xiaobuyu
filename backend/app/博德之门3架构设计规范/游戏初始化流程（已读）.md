## 一、全景流程

```
打开网站 → 标题页 → 世界选择 → 存档管理 → [新游戏: 角色创建 → 开场] / [继续: 恢复] → 游戏中
```

玩家视角的完整分支：

```
                        ┌─────────┐
                        │ 打开网站 │
                        └────┬────┘
                             │
                        ┌────▼────┐
                        │ 标题页  │  ← 品牌/氛围，仅一个"开始"按钮
                        └────┬────┘
                             │
                        ┌────▼─────┐
                        │ 世界选择  │  ← 当前只有一个世界（哥布林杀手）
                        └────┬─────┘
                             │
                     ┌───────▼────────┐
                     │  检测已有存档？  │
                     └──┬──────────┬──┘
```

### 玩家体验

打开网站，看到全屏品牌画面（世界主视觉图），配合氛围音效淡入。中央一个"开始冒险"按钮。

## 五、角色创建（新游戏）

### 玩家体验

视觉小说风格的角色创建界面。不是传统 RPG 的表格填写，而是一步步引导，每步展示选择结果的视觉反馈。

**步骤流程**：

```
1. 种族选择（6 选 1）
   └─ 展示种族立绘 + 属性加成 + 种族特性描述
2. 职业选择（8 选 1）
   └─ 展示职业立绘 + 起始技能 + 装备类型预览
3. 背景选择（7 选 1）
   └─ 展示背景描述 + 额外技能 + 起始金币
4. 属性分配（27 点购买制）
   └─ 六属性滑块 + 实时数值预览（HP/AC/先攻/技能加值）
5. 角色命名 + 可选背景故事
6. 确认总览 → 提交
```

预计耗时：3-5 分钟。

## 六、开场演出（新游戏 → 首次进入游戏）

### 玩家体验

角色创建完成后，画面渐变黑屏，然后：

1. **场景渐入** — 起始地点的背景图 fade in（如：冒险者公会大厅），配合氛围粒子
2. **GM 开场叙述** — 打字机效果展示 GM 的环境描写（毒舌旁白者风格）
3. **NPC 立绘入场** — 起始位置的关键 NPC 依次出现
4. **HUD 显示** — HP/时间/金币 HUD 淡入
5. **首组选项** — 玩家可以做的第一组操作

整个开场约 5-10 秒（含动画），玩家不需要任何操作。

### 开场叙述原则

来自玩法设计——**不做教程，世界即教程**：

| 原则 | 说明 |
|------|------|
| 无强制教程 | AI GM 本身就是最好的引导 |
| 无固定脚本 | GM 基于位置 + 世界 Lore + 角色背景即兴生成 |
| 自然开场 | 玩家发现自己在某个地方，周围有可交互的 NPC 和可去的地点 |
| 第一任务自然涌现 | 去公会看看任务板 → NPC 主动搭话 → 发现线索 |
| GM 人格展现 | 开场就展示毒舌旁白者风格，让玩家感受到 GM 的存在 |

### SSE 事件顺序

开场的 SSE 事件按严格顺序推送（前端按序处理动画）：

| 序号 | SSE 事件 | 来源 | 前端动画 | 耗时 |
|------|---------|------|---------|------|
| 1 | `scene_change` | 编排层（位置信息） | 背景图 fade in + 氛围粒子启动 | ~800ms |
| 2 | `gm_narration` | GM `narrate` 工具 | 对话框出现，打字机效果展示 GM 文本 | ~3s |
| 3 | `gm_comment` (可选) | GM `comment` 工具 | 斜体灰色旁白，短暂停留后淡出 | ~1.5s |
| 4 | `character_enter` × N | 编排层（区域 NPC 列表） | NPC 立绘依次 fade in | ~400ms × N |
| 5 | `status_update` | ❸ PlayerSlice 快照 | HUD 元素淡入 | ~300ms |
| 6 | `dialogue_options` | GM `suggest_options` 工具 | 选项按钮从底部滑入 | ~200ms |

**总计 ≈ 5-8 秒**，玩家零操作。

## 七、会话恢复（继续游戏）

### 玩家体验

从存档列表点击"继续"后：

1. **加载画面** — 简短 loading（通常 < 1 秒，除非跨设备首次需要下载云端存档）
2. **场景渐入** — 上次离开时的地点背景
3. **GM 恢复叙述** — 简短一两句话提醒玩家"你在哪里，发生了什么"
4. **HUD + 选项** — 直接可操作

## 八、首次操作 → 正式游戏循环

### 玩家体验

开场或恢复完成后，玩家可以：

| 操作 | 触发 | 后端入口 | 时间消耗 |
|------|------|---------|---------|
| 点击对话选项 | 选择 GM 给出的选项之一 | 默认跟随 `dispatch`；NPC 定向对话/对话检定走 `POST .../interact/stream` | 视选项而定 |
| 点击 NPC 交互 | 点击场景中的 NPC 立绘 | `POST .../interact/stream` | 1/6 格 |
| 自由输入文字 | 在输入框打字 | `POST .../input/stream` | 视内容而定 |
| 导航到其他地点 | 点击地图或导航按钮 | `POST .../navigate` | 1-3 格（旅行时间） |
| 查看面板 | 打开背包/角色/地图面板 | `GET .../character` 等 | 0（纯 UI） |
| **施放法术** | 点击法术面板中的法术 | `POST .../action/stream` | 1/6 格 |
| **使用物品** | 点击背包中的消耗品 | `POST .../action/stream` | 1/6 格 |
| **交互物件** | 点击场景中的可交互物 | `POST .../action/stream` | 1/6 格 |
| **装备切换** | 拖拽装备到槽位 | `POST .../action/stream` | 0（纯 UI） |

从玩家第一次消耗时间的操作开始，**时间经济系统正式启动**：

```
动作消耗时间 → TimeSlice.accumulated 累积
    → 累积达到 1.0 格 → TickCoordinator.tick_settlement()
        → 10 个 SettlementHook 按优先级执行（P10-P90，含 P35 NarrativePlanner）
        → AI Osiris 推理 → NarrativePlanner 叙事规划 → 遭遇检定 → ...
        → SceneBus 重置
        → 新的一格开始
```

## 九、异常流程

### §9.1 角色创建中断

玩家在角色创建途中关闭浏览器。

**处理**：会话已创建（`phase: "character_creation"`），PlayerSlice 为空。下次打开时：
- 存档列表显示该会话，`phase: "character_creation"`
- 点击继续 → `resume` 返回 `phase: "character_creation"` → 前端重新进入角色创建流程
- 已创建的 StateContainer（8 个已初始化的 Slice）保持不变，无需重新创建

### §9.2 开场叙述生成失败

LLM 调用超时或报错。

**处理**：
- 后端使用模板兜底：`"你身处{location_name}。{time_description}。周围有{npc_count}个人。"`
- SSE 仍然正常推送 `scene_change` + `status_update` + `dialogue_options`
- 玩家可以正常操作，只是开场文本较简陋

### §9.3 跨设备恢复冲突

设备 A 和设备 B 都有本地存档，但版本不同。

**处理**：
- 比对 `meta.json` 中的 `save_timestamp`
- 以时间戳较新者为准
- 提示用户确认（前端弹窗）
- 详见 `世界初始化流程.md` §7.4

### §9.4 WorldInstance 加载失败

世界数据文件缺失或损坏。

**处理**：
- 返回 HTTP 500 + 具体错误信息（缺失哪个 Registry 文件）
- 前端展示错误页面，引导刷新或联系管理员
- 不影响其他世界（每个世界独立加载）

## 十、端到端耗时预算

从玩家视角的关键路径耗时：

### 新游戏路径

| 步骤 | 耗时 | 瓶颈 |
|------|------|------|
| 标题页 → 点击开始 | 0（用户操作） | — |
| GET /worlds | < 100ms | 磁盘扫描 |
| POST /sessions | < 500ms | WorldInstance 首次加载（~2s），后续缓存命中 < 50ms |
| GET /character-creation/options | < 50ms | 内存读取 |
| 角色创建交互 | 3-5 分钟 | 用户操作 |
| POST /character | < 200ms | ❷ RulesEngine 计算 |
| 开场 SSE 流 | 3-5s | LLM 生成 GM 叙述 |
| **总计（不含用户操作）** | **< 6s** | **LLM 调用** |

### 继续游戏路径

| 步骤 | 耗时 | 瓶颈 |
|------|------|------|
| 存档列表渲染 | < 200ms | 查询存档 |
| POST /resume | < 1s | 本地存档读取 + GM 恢复叙述（LLM） |
| 场景渲染 | ~1s | 前端动画 |
| **总计** | **< 2s** | **本地 I/O + LLM** |

跨设备继续（首次，需下载云端存档）：额外 +1-3s（Firestore 网络延迟）。
