## 逐步调整评估

### Step 1: NPC System Prompt 组装

**代码路径**：`context_builder.py:577 build_npc_full_context()` → `_build_npc_prompt_text()` (line 1981)

**现状**：
- 开头：`"You are {name}, an NPC in a dark-fantasy CRPG world."` ← **需改**
- `## 与冒险者的关系` 只有数值，无行为指引 ← **需改**
- tool_rules 中 delta 提示 `"±5 to ±15"` ← **需改**
- 无 values/likes/dislikes 注入 ← **需改（预留）**
- `_STAGE_GUIDES` 已存在但未用于 NPC ← **复用**
- `_trust_hint` / `_romance_hint` / `_fear_hint` 已存在但未用于 NPC ← **复用**
- blackboard (thoughts/goals/mood) 注入 ← 够用
- area_situation 注入 ← 够用
- secrets trust 门控 ← 够用
- role_data 约束 (merchant/receptionist) ← 够用
- pending_topic 注入 (npc_interaction.py:404) ← 够用

**调整清单**：
1. 世界观 `"dark-fantasy CRPG world"` → `"边境小镇日常世界"`
2. 在 `## 与冒险者的关系` 后新增 `## 对话指引` block（复用 `_STAGE_GUIDES` + hints）
3. 新增 `## 你的喜好` block（读 values/likes/dislikes，无数据跳过）
4. tool_rules delta 提示改为实际钳位范围
5. CharacterTemplate 新增 values/likes/dislikes 可选字段

**涉及文件**：`context_builder.py`, `characters.py`
**涉及设计文档**：`02-NPC交互与对话.md`

### Step 2: NPC Agent 回应（LLM）

**代码路径**：`npc_interaction.py:440 executor.run_agentic(role="npc")` → LLM 调用 → 工具执行

**NPC 可调用的工具**（registry.py 过滤）：
- `speak` / `emote` — 对话输出
- `update_feeling` — 好感变化 ← **需改（delta 钳位）**
- `remember` / `recall` — 记忆
- `offer_quest` / `accept_quest` / `assign_quest` — 任务
- `offer_trade` / `sell_to_player` — 交易
- `execute_service` — 服务执行
- `reveal_secret` — 秘密揭示
- `join_party` — 入队
- `refuse` — 拒绝
- `suggest_options` — 对话选项
- `discover_clue` — 发现线索
- `offer_help` — 援助
- `update_blackboard` / `send_npc_message` — 黑板

**现状**：
- UpdateFeelingTool delta 范围 [-50, +50] ← **需改**
- WorldStateHandler validate 也是 [-50, +50] ← 不需改（tool层钳位后值已在范围内）
- RelationSlice.modify_disposition() 无 clamp ← 不需改（tool层已防）
- 其他工具 ← 够用

**调整清单**：
1. UpdateFeelingTool: 按维度钳位（approval ±3, trust ±2, romance -1~+2, fear ±3）
2. 参数描述更新

**涉及文件**：`character_tools.py`
**涉及设计文档**：`02-NPC交互与对话.md`, `05-关系与社交.md`

### 结算阶段：Settlement Hooks

**代码路径**：`_finalize_dialogue_turn()` → `tick_coordinator.process_settlement()`

#### RelationshipHook (priority 65)

**现状**：
- 正面跃迁阈值：stranger→acquaintance(approval>10), acquaintance→friend(approval>30,trust>20), friend→close_friend(trust>60), close_friend→intimate(trust>80,romance>60)
- 负面跃迁：cold/hostile/enemy

**关键问题**：设计文档说阶段跃迁 = 数值 + **关键事件双重门槛**（如 friend→close_friend 需经历 Planner 编排的"关键事件"），但**当前代码只看数值**。

**调整评估**：段一暂不改跃迁条件（纯数值门槛够用），段二随剧本系统加入事件门槛。
