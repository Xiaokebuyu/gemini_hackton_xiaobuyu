## 审查修复（P0 + P1）

### [D-001] list_all() 改为 @abstractmethod

- **文件**：`content/base.py`
- **原因**：`raise NotImplementedError` 不阻止实例化，子类可以遗漏实现
- **影响**：所有 10 个 Registry 必须实现 `list_all()`（已实现）

### [D-002] StateContainer / WorldInstance typed properties

- **文件**：`state/base.py`, `content/world.py`
- **原因**：convenience properties 返回 base type 导致下游需要 getattr 或 cast
- **方案**：`TYPE_CHECKING` 块导入具体类型 + `cast()` 返回
- **影响**：
  - `state.time` → `TimeSlice`（不再需要 getattr）
  - `state.scene` → `SceneSlice`（SceneBus 构造不再有类型不匹配）
  - `world.maps` → `MapRegistry` 等（下游可直接调用具体方法）

### [D-003] Registry _coerce_dict_mapping 提到基类

- **文件**：`content/base.py` + 8 个 Registry 文件
- **原因**：8 个 Registry 有完全相同的 `_coerce_mapping` 静态方法（128 行重复）
- **方案**：基类新增 `_coerce_dict_mapping()` 静态方法，子类直接继承
- **净减**：-128 行

### [D-004] QuestSlice.milestone_states 升级为 MilestoneState dataclass

- **文件**：`state/slices/quests.py`
- **原因**：`dict[str, str]` 丢失 `activated_tick` / `completed_tick`，NarrativePlanner 需要节奏判断
- **新类型**：`MilestoneState(state, activated_tick, completed_tick)`
- **兼容**：`restore()` 支持 `str` 和 `dict` 两种格式，向后兼容
- **影响**：`advance_milestone()` 新增可选 `tick` 参数

### [D-005] _tick_settlement 收集 SSE events

- **文件**：`orchestration/tick_coordinator.py`
- **原因**：HookResult.sse_events 被完全忽略，后续 GmNarrationHook 需要
- **方案**：`_tick_settlement()` 返回 `list[SSEEvent]`，merge 到 PipelineResult

### [D-006] SceneBusResetHook change_log.clear() 加注释

- **文件**：`orchestration/hooks/scene_reset.py`
- **说明**：change_log 与 SceneBus 同生命周期，格末统一清理
