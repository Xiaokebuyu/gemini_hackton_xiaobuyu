```python
# 旧（L1+L3 混合）:
def graphize(self, request):
    context = self._get_important_nodes_from_wg(wg)    # L3 读
    extraction = self._extract_graph_elements(...)       # L1 LLM
    self._merge_to_world_graph(wg, extraction)           # L3 写

# 新（L1 + 调用 L3）:
def graphize(self, request):
    from app.world.memory.graph_writer import get_context_nodes, merge_extraction
    context = get_context_nodes(wg, ...)                 # L3 读（函数在 L3 模块）
    extraction = self._extract_graph_elements(...)       # L1 LLM（留在自身）
    merge_extraction(wg, extraction)                     # L3 写（函数在 L3 模块）
```

## Phase B: WorldAPI 建设 ✅

### Step B1 ✅: 创建 `app/services/world_api.py`

**动作**：新建 WorldAPI 类，16 个方法全部薄委托。无权限校验（初版全放行）。

**文件**：`app/services/world_api.py`（新建，~120 行）

```python
from __future__ import annotations
import logging
from typing import Any, Dict, List, Optional, TYPE_CHECKING

if TYPE_CHECKING:
    from app.runtime.session_runtime import SessionRuntime

class WorldAPI:
    """L2 统一接口 — L1 居民能看到的全部操作。"""

    def __init__(self, session: 'SessionRuntime', role: str, agent_id: str):
        self._session = session
        self._role = role
        self._agent_id = agent_id

    # --- 玩家数值（5） ---
    def heal(self, amount: int) -> dict:
        return self._session.heal(amount)

    def damage(self, amount: int) -> dict:
        return self._session.damage(amount)

    def add_xp(self, amount: int) -> dict:
        return self._session.add_xp(amount)

    def add_item(self, item_id: str, item_name: str, quantity: int = 1) -> dict:
        return self._session.add_item(item_id, item_name, quantity)

    def remove_item(self, item_id: str, quantity: int = 1) -> dict:
        return self._session.remove_item(item_id, quantity)

    # --- 事件状态机（5） ---
    def activate_event(self, event_id: str) -> dict:
        return self._session.activate_event(event_id)

    def complete_event(self, event_id: str, outcome_key: str = "") -> dict:
        return self._session.complete_event(event_id, outcome_key)

    def fail_event(self, event_id: str, reason: str = "") -> dict:
        return self._session.fail_event(event_id, reason)

    def advance_stage(self, event_id: str, stage_id: str = "") -> dict:
        return self._session.advance_stage(event_id, stage_id)

    def complete_event_objective(self, event_id: str, objective_id: str) -> dict:
        return self._session.complete_event_objective(event_id, objective_id)

    # --- 叙事（3） ---
    def advance_chapter(self, target_chapter_id: str, transition_type: str = "normal") -> dict:
        return self._session.advance_chapter(target_chapter_id, transition_type)

    def complete_objective(self, objective_id: str) -> dict:
        return self._session.complete_objective(objective_id)

    def update_disposition(self, npc_id: str, deltas: dict, reason: str = "") -> dict:
        return self._session.update_disposition(npc_id, deltas, reason)

    # --- 记忆（2） ---
    async def recall(self, role: str, actor_id: str, seeds: list, **kwargs) -> list:
        return await self._session.recall(role=role, actor_id=actor_id, seeds=seeds, **kwargs)

    def record_memory(self, owner_id: str, memory_type: str, **kwargs) -> str:
        return self._session.record_memory(owner_id=owner_id, memory_type=memory_type, **kwargs)

    # --- Flash（1） ---
    def set_flash_result(self, prompt: str, result: bool) -> None:
        self._session.flash_results[prompt] = bool(result)
```

**验收条件**：文件可被 import，无语法错误。

## 注意事项

1. **执行顺序严格**：Phase A 先做文件搬迁，Phase B 在新路径上做 WorldAPI。不能反过来（否则 import 路径要改两遍）。

2. **`session` 字段保留**：gm_extra_tools 闭包捕获 session，Pipeline `context["_runtime_session"]` 传递 session。`AgenticContext.session` 不删，仅标记废弃。

3. **graph_writer 不改调用方**：memory_graphizer.graphize() 签名不变。内部改为调用 graph_writer 的函数。5 个调用方（memory_ops、pipeline、session_history、instance_manager、测试）无感。

4. **gm_extra_tools 不动内部逻辑**：只搬位置（Phase A），闭包捕获 session 的模式暂不改。

5. **WorldAPI lazy import**：Pipeline/teammate_service 中用方法内 import，避免启动时循环依赖。

6. **event_llm_service 只搬不拆**：它已经是纯 L1，只是放错了目录。
