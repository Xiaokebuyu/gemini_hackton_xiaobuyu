# 基础设施

## 模块概要

持久化、内容注册表、适配器端口、API 层、数据加载。

### 持久化

| 模块 | 位置 | 职责 |
|------|------|------|
| PersistencePort | `adapters/persistence.py` | 存储抽象 Protocol |
| LocalPersistence | `adapters/local_persistence.py` | 本地文件系统实现 |
| FirestorePersistence | `adapters/firestore_persistence.py` | Firestore 云端实现 |
| SessionStore | `adapters/session_store.py` | 外层 session save/load 编排 |

### 内容注册表（10 个）

| Registry | 位置 | 内容 |
|----------|------|------|
| CharacterRegistry | `content/registries/characters.py` | NPC/同伴角色模板 |
| ItemRegistry | `content/registries/items.py` | 物品/装备/消耗品 |
| SkillRegistry | `content/registries/skills.py` | 技能定义 |
| ClassRegistry | `content/registries/classes.py` | 职业/子职业模板 |
| MonsterRegistry | `content/registries/monsters.py` | 怪物定义 |
| MapRegistry | `content/registries/maps.py` | 地图/区域/位置/房间 |
| FactionRegistry | `content/registries/factions.py` | 阵营定义 |
| LoreRegistry | `content/registries/lore.py` | 世界知识/历史 |
| QuestRegistry | `content/registries/quests.py` | 任务/里程碑模板 |
| TagRegistry | `content/registries/tag.py` | 标签过滤 |

### API 与应用层

| 模块 | 位置 | 职责 |
|------|------|------|
| main.py | `app/main.py` | FastAPI 入口和端点定义 |
| api_models.py | `app/api_models.py` | Pydantic HTTP 模型 |
| interaction_service.py | `app/interaction_service.py` | 应用层交互执行编排 |
| interaction_views.py | `app/interaction_views.py` | 交互响应 payload 构建 |
| scene_views.py | `app/scene_views.py` | 场景状态 payload 构建 |
| opening_views.py | `app/opening_views.py` | 新游戏开场 payload 构建 |
| resume_views.py | `app/resume_views.py` | 续存恢复 payload 构建 |
| utterance_orchestration.py | `app/utterance_orchestration.py` | 统一发言编排 |

### 数据加载

| 模块 | 位置 | 职责 |
|------|------|------|
| world_data_loader.py | `app/world_data_loader.py` | goblin_slayer 数据加载 |
| game_data_loader_v2.py | `app/game_data_loader_v2.py` | V2 世界数据加载 |
| v2_data_pipeline.py | `app/v2_data_pipeline.py` | V2 数据处理管线 |
| world_seed.py | `app/world_seed.py` | 内置合成世界数据 |
| design_skill_provider.py | `app/design_skill_provider.py` | 本地设计模板文件读取 |

### 其他

| 模块 | 位置 | 职责 |
|------|------|------|
| bootstrap.py | `game_core/bootstrap.py` | 默认运行时组装 |
| runtime.py | `game_core/runtime.py` | 应用层 session 生命周期服务 |
| admin_coordinator.py | `app/admin_coordinator.py` | session 缓存 + per-session 锁 |
| asset_resolver.py | `app/asset_resolver.py` | AI 生成素材 LRU 缓存 |
| image_prefetch.py | `app/image_prefetch.py` | 动态子区域背景图预取 |
