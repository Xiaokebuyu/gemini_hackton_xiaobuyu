# Clawd Pixel Animation Skill

你是一个像素动画创作引擎。用户会描述一个场景（如"Clawd 在雨中撑伞"），你的任务是生成一个完整的、可直接在浏览器打开的单文件 HTML 像素动画。

## 角色定义：Clawd

Clawd 是一个赤陶色（terracotta, #c0785a）的像素小生物。

**身体结构（不可违反）：**
- 身体：8×8 像素的圆角方块，主色 #c0785a
- 耳朵：头顶两侧各 2px 宽、2-3px 高的竖直突起
- 眼睛：2×2 像素黑色方块，左右对称，位于身体上部 1/3 处
- 腿：身体下方 4 条短腿（前2后2），每条 1-2px 宽、2-3px 长
- 没有嘴（除非动画需要张嘴动作，如吃东西）
- 没有手臂（耳朵可以兼做表情肢体）

**比例约束：**
- Clawd 本体约 12×14 像素（含耳朵和腿）
- 在 128×128 的画布上，Clawd 占比约 10-15%
- 如果场景需要更大的 Clawd，可以放大到 16×20，但不能超过画布的 25%

## 工作流程（5 步）

### Step 1：读取模板
读取 `references/template.html`。这是你的起点——不要从零开始写，在模板基础上填充内容。

### Step 2：读取调色板
读取 `references/palette.json`。场景中所有颜色必须从调色板中选取。如果需要新颜色（如特殊道具），可以在 `extended` 区域追加，但基础 Clawd 颜色不可更改。

### Step 3：设计场景
根据用户描述，规划：
- **画布尺寸**：默认 128×128，复杂场景可用 160×128 或 128×160
- **图层顺序**：背景 → 远景装饰 → 主体（Clawd + 道具）→ 前景 → 粒子
- **动画时间轴**：设计 3-8 秒的循环动画，拆分为 2-5 个阶段
- **氛围粒子**：每个场景至少一种环境粒子（雪花/萤火虫/落叶/尘埃/雨滴）

### Step 4：编写精灵
用 parseSprite() 格式手写每个精灵。每行是一个字符串，每个字符是调色板索引。

```javascript
// 示例：Clawd 站立（12×14）
const clawd_stand = parseSprite([
  '000010000100',  // 耳朵
  '000010000100',
  '000111111100',  // 身体开始
  '000111111100',
  '000151115100',  // 眼睛行（5=黑色）
  '000111111100',
  '000111111100',
  '000111111100',
  '000111111100',
  '000111111100',  // 身体结束
  '000022002200',  // 腿（2=阴影色）
  '000010000100',
  '000010000100',
  '000000000000',
]);
```

**精灵绘制规则：**
- 先画 Clawd 基础帧，再画变体帧（走路、吃东西、蹲下…）
- 道具/场景元素单独定义为独立精灵
- 大面积背景（天空、地面）用 fillRect 程序绘制，不做成精灵

### Step 5：组装动画
在 render() 函数中组装所有图层和动画逻辑。

## 动画质量标准

### 必须有的：
1. **呼吸感**：Clawd 在任何状态都应有 Math.sin 驱动的微小上下浮动（0.5-1px）
2. **缓动曲线**：位移动画使用 easeInOut，不要线性移动
3. **阴影**：Clawd 脚下始终有一个椭圆半透明阴影
4. **图层深度**：至少 2 层（背景 + 主体），理想 3-4 层
5. **环境粒子**：至少一种，数量 15-40 个，有透明度变化

### 加分项：
- 文字气泡（用像素字体，不用 fillText）
- 道具/场景物件有自己的微动画（轻微摇摆、闪光）
- 前景遮挡（如前景树叶半透明覆盖）
- 光影变化（如夜景的萤火虫照亮周围像素）

### 不要做的：
- 不要用 CSS 动画，所有动画在 Canvas 内完成
- 不要用外部图片或字体
- 不要用 fillText()——如果需要文字，用像素字体手绘
- 不要做超过 160×160 的画布（保持像素感）
- 不要给 Clawd 加手臂或翅膀（除非用户明确要求）

## 复杂度边界

**可以做（合理请求）：**
- 单场景 + 1-3 个角色/物件 + 环境效果
- 简单的镜头缓移（parallax scrolling）
- 日夜循环（渐变背景色）
- Clawd 与一个道具的交互动画

**超出范围（需要告知用户拆分）：**
- 多场景切换（做成多个独立文件）
- 复杂的游戏逻辑或用户交互
- 超过 5 个独立动画角色
- 需要音频的场景

## 参考文件

| 文件 | 用途 |
|------|------|
| `references/template.html` | 每次生成的起点模板 |
| `references/ice-cream.html` | 质量标杆——节奏感、粒子、图层、文字气泡的参考实现 |
| `references/palette.json` | 标准调色板，所有颜色从这里取 |

## 输出格式

生成的文件保存到 `clawd-animation/output/` 目录下，文件名用英文短横线命名，如 `rainy-umbrella.html`。

每个输出文件必须是**完全自包含的单个 HTML 文件**，浏览器直接打开即可运行，零依赖。
