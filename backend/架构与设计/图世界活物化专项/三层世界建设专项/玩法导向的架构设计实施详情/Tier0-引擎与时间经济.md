## 实施范围

Tier 0 是地基，核心目标：

1. **时间经济落地**：行动消耗时间格，一天 24 格结构
2. **引擎 pre-tick/post-tick 形式化**：按钮动作 → 引擎机械执行 → SceneBus → Agent 叙述
3. **GM 工具收回**：GM 从 16 个状态变更工具 → 零变更纯只读
4. **IntentResolver 替换**：删除意图猜测，前端发结构化 action
