## 设计决策

### 核心原则：不复建 AreaRuntime，直接用现有设施

AreaRuntime 是一个 Firestore-backed 的有状态对象。它的职责已被三个系统瓜分：

| 职责 | 新归属 | 理由 |
|------|--------|------|
| 事件状态机 | BehaviorEngine（已完成） | WorldGraph 驱动 |
| 区域动态状态（visit_count 等） | WorldGraph 节点 `.state` | IntentExecutor 已维护 |
| 区域上下文组装 | ContextAssembler 内置函数 | 数据源 = WorldInstance（静态） + WorldGraph（动态） |
| 条件中文摘要 | 独立模块函数 | 纯函数，零状态依赖 |
| NPC 上下文 | InstanceManager（已完成） | 双层认知架构 |
| 行为记录 (record_action) | 删除 | VisitSummary 无消费方 |
| Firestore 持久化 | 删除 | WorldGraph 快照统一管理 |

### `self.current_area` 字段处理

**删除**。ContextAssembler 改为接收 `(world: WorldInstance, session: SessionRuntime)` 后自行查询 `session.area_id` + `world.get_area_definition(area_id)`，不再需要 SessionRuntime 持有 AreaRuntime 实例。

## Step 3：ContextAssembler 内置上下文生成

**目标**：`ContextAssembler.assemble()` 不再调用 `area.get_area_context()` / `area.get_location_context()`，改为自身内置函数，数据源 = `WorldInstance` + `WorldGraph`。

### 3a：实现 `_build_area_context()` 静态方法

在 `ContextAssembler` 中新增：

```python
@staticmethod
def _build_area_context(world: Any, session: Any) -> Dict[str, Any]:
    """Layer 2 区域上下文 — 替代 AreaRuntime.get_area_context()。

    数据源：WorldInstance.area_registry（静态） + WorldGraph（动态状态）
    """
    area_id = getattr(session, "area_id", None) or getattr(session, "player_location", None)
    if not area_id or not world:
        return {}

    defn = world.get_area_definition(area_id)
    if not defn:
        return {}

    # 子地点列表
    wg = getattr(session, "world_graph", None)
    discovered = set()
    if wg and wg.has_node(area_id):
        discovered = set(wg.get_node(area_id).state.get("discovered_sub_locations", []))

    sub_locations = []
    for sl in defn.sub_locations:
        sub_locations.append({
            "id": sl.id,
            "name": sl.name,
            "description": sl.description if sl.id in discovered else "",
            "discovered": sl.id in discovered,
            "interaction_type": sl.interaction_type,
            "resident_npcs": sl.resident_npcs,
            "available_actions": sl.available_actions,
        })

    # NPC 列表
    area_npcs = []
    sub_loc = getattr(session, "sub_location", None)
    if sub_loc and hasattr(world, "get_characters_at_sublocation"):
        raw = world.get_characters_at_sublocation(area_id, sub_loc)
    elif hasattr(world, "get_characters_in_area"):
        raw = world.get_characters_in_area(area_id)
    else:
        raw = []
    area_npcs = [_clean_npc_for_context(c) for c in raw]

    # 事件摘要
    event_summaries = []
    if session and hasattr(session, "get_event_summaries_from_graph"):
        event_summaries = session.get_event_summaries_from_graph(area_id)

    # 怪物/技能/物品（与原 AreaRuntime 逻辑一致）
    monsters, skills, items = _build_combat_entities(world, defn, session)

    # 连接
    connections = [
        {"target": c.target_area_id, "type": c.connection_type,
         "travel_time": c.travel_time, "description": c.description,
         "requirements": c.requirements}
        for c in defn.connections
    ]

    visit_count = 0
    if wg and wg.has_node(area_id):
        visit_count = wg.get_node(area_id).state.get("visit_count", 0)

    return {
        "area_id": area_id,
        "name": defn.name,
        "description": defn.description,
        "danger_level": defn.danger_level,
        "area_type": defn.area_type,
        "tags": defn.tags,
        "key_features": defn.key_features,
        "available_actions": defn.available_actions,
        "ambient_description": defn.ambient_description,
        "sub_locations": sub_locations,
        "npcs": area_npcs,
        "events": event_summaries,
        "monsters": monsters,
        "available_skills": skills,
        "item_reference": items,
        "visit_count": visit_count,
        "connections": connections,
    }
```

### 3b：实现 `_build_location_context()` 静态方法

```python
@staticmethod
def _build_location_context(world: Any, session: Any) -> Optional[Dict[str, Any]]:
    """Layer 3 子地点上下文 — 替代 AreaRuntime.get_location_context()。"""
    sub_id = getattr(session, "sub_location", None)
    area_id = getattr(session, "area_id", None) or getattr(session, "player_location", None)
    if not sub_id or not area_id or not world:
        return None

    defn = world.get_area_definition(area_id)
    if not defn:
        return None

    sl = defn.get_sub_location(sub_id)
    if not sl:
        return None

    return {
        "id": sl.id,
        "name": sl.name,
        "description": sl.description,
        "interaction_type": sl.interaction_type,
        "resident_npcs": sl.resident_npcs,
        "available_actions": sl.available_actions,
    }
```

## `discovered_sub_locations` 数据路径

**旧路径**（已断）：AreaRuntime.load() 从 Firestore 读取 → AreaState.discovered_sub_locations → get_area_context() 用它过滤子地点描述。

**现状**：AreaRuntime.load() 抛 NotImplementedError → discovered 始终为空集 → 所有子地点描述始终为空字符串。

**新方案**：在 `_build_area_context()` 中，所有子地点默认 `discovered=True`（显示描述）。后续如需恢复"探索发现"机制，可在 WorldGraph area 节点 state 中加 `discovered_sub_locations` 列表。当前不实现（YAGNI）。
