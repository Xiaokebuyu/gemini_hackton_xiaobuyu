## 一、定位与范围

本文档是"Agent 层 / 编排层"改造的可执行方案。L3+L2 完成后，底层和中层已具备：

- WorldGraph 是唯一图容器，含记忆节点类型 + 索引 + 查询
- SpreadingActivation 直接在 WorldGraph 上运行（同步，纯内存）
- MemoryGraphizer 写入目标已切到 WorldGraph（接收 `world_graph` + `owner_node_id`）
- RecallOrchestrator 已简化为同步 WorldGraph 查询（无 Firestore I/O）
- AgenticContext 已删除 `graph_store` 字段
- MemoryGraph 已删除

**L1 的工作是**：

1. Agent 工具不再直接持有 `recall_orchestrator`，改为通过 `session` 门面访问记忆能力
2. `recall_experience` 返回值从"ID + 分数"升级为"名称 + 摘要 + 分数"
3. MemoryGraphizer 的上下文节点获取从 Firestore 改为 WorldGraph 查询
4. AdminEventService 从"直写图 + perspective transform"改为"SceneBus 广播 + 各角色自行图谱化"
5. 清理死文件 + 观测指标接入

**不做什么**：

1. 不改 ContextWindow 内部逻辑（阈值、消息选择策略不变）
2. 不改 MemoryGraphizer 的 LLM 提取 prompt（只改上下文节点获取方式）
3. 不改 SceneBus 核心结构（成员模型、visibility 过滤不变）
4. 不新增记忆工具（工具集不变，只改现有工具实现）

## 二、关键设计决策（本阶段确认）

### D-L1.1 recall_orchestrator 收入 SessionRuntime 门面

L2 保留了 `recall_orchestrator` 在 AgenticContext 中。L1 将其移入 SessionRuntime，工具通过 `ctx.session.recall()` 访问。

**理由**：L3 后 RecallOrchestrator 变为无状态工具（~40 行），唯一依赖是 `world_graph`（已在 session 上）。收入 session 后工具侧更简洁，且对齐中层"记忆门面"目标。

### D-L1.2 per-character 记忆模型

不使用共享事件节点 + 视角边。每个在场角色通过各自的 ContextWindow → MemoryGraphizer 生成自己视角的记忆节点（owner = 自己）。

**SceneBus 成员模型决定"谁知道什么"**：
- 在场（bus member）→ ContextWindow 收到条目 → 触发阈值后各自图谱化
- 不在场 → 无感知 → 无记忆节点
- 传闻 = NPC 之间对话，传入对方 ContextWindow，各自图谱化

**被动旁观者（方案 B）**：暂不为被动旁观者生成记忆节点。未来可升级为方案 A（轻量旁观记忆）。

### D-L1.3 AdminEventService 改为 SceneBus 广播

系统级事件（章节转换、任务完成等）不再由 AdminEventService 直写图 + FlashService 分发。改为通过 SceneBus 广播（type=SYSTEM），只有在场 bus members 感知。各角色通过 ContextWindow 自行积累和图谱化。

**影响**：L3 Phase 3.4 已对齐 — 只做 I/O 层迁移（GraphStore → WorldGraph），分发策略由本阶段（L1-5）独立定义。

## 五、Phase L1-2：SessionRuntime 记忆门面

### 5.1 新增 recall 门面方法

**文件**：`app/runtime/session_runtime.py`

```python
def recall(
    self,
    *,
    role: str,
    actor_id: str,
    seeds: List[str],
    intent_type: Optional[str] = None,
    limit: int = 10,
) -> List[Dict[str, Any]]:
    """记忆召回门面 — Agent 工具的唯一入口。"""
    if not self.world_graph:
        return []

    result = self._recall_orchestrator.recall_for_role(
        world_graph=self.world_graph,
        role=role,
        character_id=actor_id,
        seed_nodes=seeds,
        intent_type=intent_type,
    )

    if not result.activated_nodes:
        return []

    # 富化返回值：ID + 名称 + 摘要 + 分数
    top = sorted(result.activated_nodes.items(), key=lambda x: x[1], reverse=True)[:limit]
    memories = []
    for node_id, score in top:
        node = self.world_graph.get_node(node_id)
        if node:
            memories.append({
                "concept": node.name or node_id,
                "summary": node.properties.get("summary", ""),
                "type": str(node.type),
                "relevance": round(score, 2),
            })
    return memories
```

### 5.2 新增 record_memory 写门面方法

**文件**：`app/runtime/session_runtime.py`

```python
def record_memory(
    self,
    *,
    owner_id: str,
    memory_type: str,   # "impression" / "memory_event" / "knowledge"
    name: str,
    summary: str,
    importance: float = 0.5,
    role: str = "gm",   # 调用者角色 — 中层做权限校验
    **properties,
) -> str:
    """记忆写入门面 — Agent 工具的唯一入口。中层负责权限校验。"""
    if not self.world_graph:
        raise RuntimeError("WorldGraph not initialized")

    # 权限校验（对齐三层"中层负责权限"原则）
    if role == "npc" and memory_type not in ("impression",):
        raise PermissionError(f"NPC role cannot create {memory_type}")
    if role == "teammate" and memory_type not in ("impression", "memory_event"):
        raise PermissionError(f"Teammate role cannot create {memory_type}")
    # GM 无限制

    node_id = self.world_graph.add_node(
        node_type=memory_type,
        name=name,
        properties={"summary": summary, **properties},
        importance=importance,
    )
    self.world_graph.add_edge(owner_id, node_id, "has_memory")
    return node_id
```

**设计要点**：
- 与 `recall()` 对称，形成完整的记忆读写门面
- 权限校验在中层完成（对齐三层设计"中层负责权限"原则）
- 上层工具（form_impression / create_memory）调用此门面，不直触 world_graph

### 5.3 RecallOrchestrator 内部化

RecallOrchestrator 不再作为公共服务暴露。改为 SessionRuntime 内部按需构建：


**按需构建原因**：WorldGraph 在 `__init__` 时未就绪（restore 后才有），按需构建更安全。

AdminCoordinator 不再创建和传递 RecallOrchestrator 实例。PipelineOrchestrator 不再持有 `self.recall_orchestrator`。

### 7.1 _get_important_nodes() 改为 WorldGraph 查询

**文件**：`app/services/memory_graphizer.py`（lines 721-824）

**当前**：从 Firestore 加载 character scope + world scope，最多 50 个节点供 LLM 引用。

**改造后**：从 WorldGraph 直接查询。

```python
# ===== 旧 =====
async def _get_important_nodes(
    self, world_id: str, npc_id: str,
    limit: int = 50, current_scene: Optional[str] = None,
) -> List[Dict[str, Any]]:
    # Part 1: character scope from Firestore
    char_data = await self.graph_store.load_graph_v2(
        world_id, GraphScope.character(npc_id))
    # Part 2: world scope from Firestore (scene-local + global)
    world_data = await self.graph_store.load_graph_v2(
        world_id, GraphScope.world())
    ...

# ===== 新 =====
def _get_important_nodes(
    self, world_graph: WorldGraph, owner_id: str,
    limit: int = 50, current_scene: Optional[str] = None,
) -> List[Dict[str, Any]]:
    """从 WorldGraph 查询已有重要节点，供 LLM 引用避免重复创建。"""
    nodes: List[Dict[str, Any]] = []
    seen: Set[str] = set()

    # Part 1: 该角色的记忆节点（按 importance 排序）
    char_limit = min(limit, 30)
    owner_memories = world_graph.find_memories_of(owner_id)
    owner_memories.sort(key=lambda n: n.importance, reverse=True)
    for n in owner_memories[:char_limit]:
        nodes.append({
            "id": n.id, "type": str(n.type), "name": n.name,
            "importance": n.importance, "properties": n.properties,
        })
        seen.add(n.id)

    # Part 2: 场景附近节点（如有 current_scene）
    remaining = limit - len(nodes)
    if remaining > 0 and current_scene:
        for neighbor_id, edge_data in world_graph.neighbors(current_scene):
            if neighbor_id not in seen and remaining > 0:
                node = world_graph.get_node(neighbor_id)
                if node:
                    nodes.append({
                        "id": node.id, "type": str(node.type), "name": node.name,
                        "importance": node.importance, "properties": node.properties,
                    })
                    seen.add(node.id)
                    remaining -= 1

    # Part 3: 全局高重要性节点补充
    remaining = limit - len(nodes)
    if remaining > 0:
        for ntype in ["npc", "location", "area"]:
            for node in world_graph.get_by_type(ntype):
                if node.id not in seen and node.importance >= 0.5:
                    nodes.append({
                        "id": node.id, "type": str(node.type), "name": node.name,
                        "importance": node.importance, "properties": node.properties,
                    })
                    seen.add(node.id)
                    remaining -= 1
                    if remaining <= 0:
                        break
            if remaining <= 0:
                break

    return nodes
```

**关键变化**：
- `async def` → `def`（纯内存查询，无 I/O）
- 参数从 `(world_id, npc_id)` 改为 `(world_graph, owner_id)`
- 不再需要 `self.graph_store`

## 八、Phase L1-5：AdminEventService 改为 SceneBus 广播

### 8.1 设计变更

**当前 AdminEventService.ingest_event() 流程**（`event_service.py:54-175`）：

```
GMEventIngestRequest
  → 写入 world scope (GraphStore)
  → 确定 recipients（participants + witnesses + visibility）
  → 为每个 recipient 做 perspective transform（LLM 生成视角特化版本）
  → FlashService.ingest_event() 写入各 character scope
```

**改造后流程**：

```
GMEventIngestRequest
  → 构建 BusEntry(type=SYSTEM, data=event_payload)
  → SceneBus.publish(entry)
  → 在场 bus members 自然感知
  → 各角色 ContextWindow 积累 → 触发阈值后各自图谱化
```

### 8.2 ingest_event() 改写

```python

        await self.graph_store.upsert_node_v2(world_id, gm_scope, node)

# ===== 新 =====
def ingest_event(self, session: SessionRuntime, request: GMEventIngestRequest) -> None:
    """将系统事件广播到 SceneBus，由各角色自行感知和图谱化。"""
    scene_bus = session.scene_bus
    if not scene_bus:
        logger.warning("[EventService] No SceneBus available, event dropped")
        return

    # 构建系统事件 BusEntry
    entry = BusEntry(
        actor="engine",
        actor_name="System",
        type=BusEntryType.SYSTEM,
        content=request.description or request.event_name,
        data={
            "event_type": request.event_type,
            "event_name": request.event_name,
            "participants": request.participants or [],
            "details": request.details or {},
        },
        visibility="public",
    )
    scene_bus.publish(entry)
```
