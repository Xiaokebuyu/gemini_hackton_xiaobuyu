## 层级分类标准

| 层 | 定义 | 判定标准 |
|----|------|----------|
| **L1 Agent** | 决策层，含 LLM 调用 | 文件内有 LLM/Gemini 调用，或做 Agent 决策逻辑 |
| **L2 API** | 编排/接口/权限层 | 路由、管线编排、MCP 工具注册、服务协调 |
| **L3 Engine** | 纯机械引擎层 | 零 AI，纯数据/状态/算法/存储 |
| **Shared** | 跨层数据模型 | Pydantic 模型、常量、协议定义 |
| **Infra** | 基础设施 | 启动、配置、依赖注入 |
| **Offline** | 离线工具 | CLI、数据提取、不参与运行时 |
